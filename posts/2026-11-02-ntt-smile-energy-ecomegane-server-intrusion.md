# NTTスマイルエナジー「エコめがね」 ― 不正アクセスでサービス全面停止

## 要点

### 発表された事実

- NTTスマイルエナジーは2026年10月30日、太陽光発電遠隔監視サービス「エコめがね」のWebサーバーで外部からの不正アクセスの形跡を確認し、サーバー通信の完全遮断とデータベースサーバーの緊急停止をしたと公表した（[NTTスマイルエナジー 10月30日の発表](https://nttse.com/news/pressrelease/2026/10-30/3288/)）。
- その後の調査で、顧客情報を管理するデータベースサーバーにも攻撃の形跡があり、顧客情報が社外へ漏えいした可能性があると判断した（同）。
- 対象は、施主・パートナー企業の氏名・企業名、住所、電話番号、メールアドレスと、サービスログイン用のIDおよびパスワード。件数は精査中（同）。
- 侵入経路と技術的な原因は特定できていない（同）。
- 太陽光発電設備の発電・売電は止まらないが、異常・停止を知らせるアラートメールが届かず、新規設置の開通登録も見合わせている。再開時期は未定（同）。

### わかっていないこと

- 侵入経路と原因
- 漏えいした可能性のある件数
- ログイン用パスワードがどのような形で保存されていたか（平文か、ハッシュ化などをしていたか）
- サービス再開の時期と順番

### 関係しそうな既知の手口

- インターネットに公開されたWebアプリケーションの既知の脆弱性や管理不備を探索して悪用する手口。JPCERT/CCが国内で相次ぐ被害について注意喚起している（考察。本件の原因とは確認されていない）。

## 概要

- 太陽光発電所の発電状況を遠隔で見守る「エコめがね」のWebサーバーが不正アクセスを受けた。
- 同社はクラウド上の全サーバーの通信を遮断し、サービスは全面停止中。
- 顧客の連絡先に加えて、ログインIDとパスワードも漏えいした可能性がある。

> この記事では、公式発表・報道で確認できた内容を「事実」、筆者の推測や意見を「考察」として分けて書いています。確認できなかった情報は書いていません。

## 発表内容の整理

**事実（NTTスマイルエナジーの10月30日の発表による）**

| 項目 | 内容 |
| --- | --- |
| 被害を受けたもの | エコめがねのWebサーバー、顧客情報を管理するデータベースサーバー（攻撃の形跡） |
| 漏えいの可能性がある情報 | 施主・パートナー企業の氏名／企業名、住所、電話番号、メールアドレス、サービスログイン用のIDとパスワード |
| 件数 | 精査中 |
| 原因 | 侵入経路・技術的原因は特定に至っていない。外部専門機関と調査中 |
| 現在の状態 | 全システムと外部通信を遮断。利用者はログインもパスワード変更もできない |
| 発電設備への影響 | 発電・売電は継続。異常検知時のアラートメールは配信されない。新規設置の開通登録・設定は見合わせ |
| 再開 | 時期未定。安全を確認できたサービスから順次再開する方針 |
| 問い合わせ | 事業企画部 info@nttse.com |

**考察**

漏えいの可能性がある項目に「ログイン用のパスワード」が明記されているため、エコめがねと同じパスワードを別のサービスで使っている人は、そちらを先に変える必要がある。エコめがね自体は止まっていてパスワード変更ができないため、再開時に強制変更などの手順が示されるかが焦点になる（考察）。

発電所の監視サービスが止まると、パワーコンディショナーの停止などに所有者が気づきにくくなる。データの漏えいとは別に、停止が長引くほど売電の取りこぼしという形で影響が出る可能性がある（考察）。

## 関係しそうな既知の手口

**事実（既知の知見）**

- JPCERT/CCは、国内組織への不正アクセスでは標的ごとにさまざまな既知の脆弱性をスキャンして悪用を試みたり、環境設定ファイルやバックアップファイルを盗んだりする手口が確認されているとして注意を呼びかけている（[JPCERT/CC 注意喚起](https://www.jpcert.or.jp/at/2026/at260030.html)）。

**考察**

エコめがねの侵入経路は公表されておらず、この注意喚起の手口に当たるかはわからない。ただ、Webサーバーで最初に検知し、のちにデータベースサーバーにも攻撃の形跡が見つかった流れは、公開サーバーを足がかりに内部へ広げる典型的な経過と重なる（考察）。

## 利用者・運用者がいまできること

- エコめがねのIDとパスワードを他のサービスでも使っている場合は、そちらのパスワードを変更する。
- 同社や関係企業を装ったメール・SMS・電話に注意する。同社はメールやSMSでクレジットカード情報、銀行口座番号、パスワードの入力を求めることはないとしている。
- アラートメールが止まっているため、発電所の所有者・保守事業者は、パワーコンディショナーの表示や売電量を現地や別の手段で確認する（考察）。
