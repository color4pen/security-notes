# プレイド「KARTE」 ― 不正アクセスを検知し全機能を停止

## 要点

### 発表された事実

- プレイドは2026年11月13日、同社が提供する「KARTE」に対する第三者からの不正アクセスを検知し、緊急メンテナンスとしてKARTE全体のサービスを停止したと適時開示した（[プレイド 適時開示](https://pdf.irpocket.com/C4165/xoA3/Laiu/qCUD/WYIe.pdf)）。
- 対象はKARTEを利用するすべてのプロジェクト。Web・アプリの計測、各種配信、管理画面の操作を含む全機能を、一斉ではなく順次停止する（同）。
- ステータスページは同日14時44分に停止を告知した。KARTE Messageの一括メール配信は途中で止まる場合があり、KARTE Datahubのジョブフローで処理中のデータ連携は失敗する場合があるとしている。終了時期は未定（[KARTE Status](https://status.karte.io/)）。
- 同日23時35分の更新で、「外部に漏洩した可能性のある情報を確認し、該当のお客様にはメールにてご連絡させていただきました」と報告した（同）。
- 2026年12月期の業績への影響は精査中（[プレイド 適時開示](https://pdf.irpocket.com/C4165/xoA3/Laiu/qCUD/WYIe.pdf)）。
- 【2026-11-15追記】ステータスページは11月14日21時05分の更新で、「引き続き不正アクセスの影響があった範囲を調査中でございますが、大きな続報はない状態です」とし、サービス再開の目処は未定と報告した。今後は同ページで定期的に進捗を更新し、次回は15日午前11時ごろの予定（[KARTE Status](https://status.karte.io/)）。同日18時03分にも、影響範囲を調査中・再開未定との更新があった（[日本時事新聞](https://jpjj.jp/articles/plaid-karte-unauthorized-access-halt/)）。
- 【2026-11-15夕追記】11月15日10時37分の更新で、全サービスの停止は「当社管理下のシステム」での被害拡大と継続的な情報流出を防ぐための「封じ込め（隔離・遮断）」を最優先にした緊急措置だと説明した。対象環境のネットワーク遮断は完了し、新たな不正アクセスや継続的な情報流出は食い止められている状態としている。現在はサービス停止前までに生じた事実関係と影響範囲を調べている（[KARTE Status](https://status.karte.io/)）。
- 【2026-11-15夕追記】同日16時01分の更新で、漏えいした可能性のある情報が該当する顧客について、「KARTEの不具合・障害等の連絡先として当社にご登録いただいているメールアドレス等」への連絡を開始したと報告した。あわせて、KARTEと外部サービスとの連携用認証情報（シークレットキー、アクセストークン等）の無効化作業を、連絡済みの顧客にも改めて依頼した。再開の目処は未定で、次回更新は21時ごろの予定（同）。
- 【2026-11-16追記】11月15日20時52分の更新では、影響範囲を引き続き調査中で「大きな続報はない状態」とし、再開の目処は未定のまま。次回は16日午前11時ごろに更新する予定（[KARTE Status](https://status.karte.io/)）。
- 【2026-11-16夕追記】11月16日10時50分と15時55分の更新でも、影響範囲は調査中で「大きな続報はない状態」、再開の目処は未定とした。次回は21時ごろの予定（[KARTE Status](https://status.karte.io/)）。
- 【2026-11-16夕追記】利用企業側の公表が出始めた。コンフィデンス・インターワークスは11月16日の第一報で、グループ会社インターワークスが運営する求人サイト「工場ワークス」からメール・LINE配信などのためKARTEに連携していた会員情報の一部（氏名、メールアドレス、電話番号、生年月日、住所など）が、第三者に閲覧・取得された可能性があると公表した。件数や対象者は精査中で、ログインパスワードはKARTEに連携しておらず、工場ワークス本体への不正アクセスではないとしている。KARTE基盤を使うRightTouchの「QANT」各製品も一部機能を止めており、11月15日10時41分に漏えいの可能性がある情報を確認して該当顧客への連絡を始めたと報告した（[セキュリティ対策Lab](https://rocket-boys.co.jp/security-measures-lab/karte_unauthorized_access_affected_companies_roundup_2026/)）。

- 【2026-11-17追記】プレイドは11月16日、調査の結果、利用企業から預かっている情報のうち個人情報を含む可能性のある一部の情報の漏えいを確認したと発表した。11月13日未明、第三者が同社サーバーの脆弱性を悪用してシステムやデータベースの接続用認証情報を窃取し、データベース等からデータを外部に読み出した。窃取した認証情報で同社アカウントを乗っ取り、管理画面への不正アクセスも発生した。同社は同日8時59分に検知し、14時27分ごろからサーバーを停止、15時23分ごろまでに認証情報の無効化と攻撃元からの通信遮断を終えた。以降、新たな不正アクセスは確認されていない（[プレイド 適時開示 11/16（PDF）](https://japanir.jp/wp-content/uploads/2026/11/4165-20261116-01.pdf)）。
- 【2026-11-17追記】漏えいを確認した情報は、①KARTEのアカウントとして登録されたメールアドレス79,249件、②外部サービスとの連携に使う認証情報（シークレットキー、アクセストークン等、件数調査中）、③利用企業が自社の会員情報などを「紐付けテーブル」機能などで取り込んだデータの一部（件数調査中、項目によっては個人情報を含む）。個人情報保護委員会への報告と警察への相談を進めている。外部セキュリティ調査を予定し、再開時期は未定（同）。
- 【2026-11-17追記】利用企業側の公表が相次いだ。四国電力は11月16日、会員制Webサービス「よんでんコンシェルジュ」の登録者約60万件（氏名、メールアドレス〈ログインID〉、住所、お知らせメール希望有無、個人会員は性別・誕生日）が外部に流出したと発表した。カード・口座情報とパスワードは対象外（[四国電力（PDF）](https://www.yonden.co.jp/press/2026/__icsFiles/afieldfile/2026/11/16/pr003.pdf)）。阪急阪神ホテルズは同日、「阪急阪神第一ホテルグループメンバーズクラブ」会員等の情報最大331,586件（氏名、年齢、住所、電話番号、メールアドレスなど。ホテル利用実績を含む可能性あり）の漏えいを公表した（[阪急阪神ホテルズ](https://www.hankyu-hotel.com/topics/2026/GPDetailPage)）。テレビ東京も同日、「テレ東BIZ」の基盤である「テレビ東京ID」登録者の氏名・メールアドレス・ユーザーID・視聴履歴などが漏えいした可能性があると公表した（件数はプレイドが精査中）（[テレビ東京（PDF）](https://www.tv-tokyo.co.jp/kaisha/pdf/20261116.pdf)）。3社とも11月15日にプレイドから報告を受けたとしている。

### わかったこと

- 【2026-11-17追記】原因：サーバーの脆弱性を悪用され、接続用認証情報を窃取されてデータを読み出された。アカウント乗っ取りによる管理画面への不正アクセスもあった（11月16日発表。脆弱性の中身は未公表）。
- 【2026-11-17追記】漏えいした情報の種類：KARTEアカウントのメールアドレス79,249件、外部連携用の認証情報、利用企業が取り込んだ顧客データの一部（11月16日発表）。

### わかっていないこと

- 悪用されたサーバーの脆弱性の中身（【2026-11-17追記】11月16日の発表で、脆弱性悪用→認証情報窃取→データ読み出しという流れと、13日未明の発生は判明した）。
- 外部連携用の認証情報と、利用企業が取り込んだデータの件数、対象の利用企業の数（【2026-11-17追記】情報の種類は11月16日に判明。件数はアカウントのメールアドレス79,249件のみ公表）。
- KARTEを使う企業のうち、自社の顧客情報の漏えいとして公表するところがどこまで広がるか（【2026-11-16夕追記】工場ワークスが11月16日に第一報を出した。【2026-11-17追記】同日、四国電力〈約60万件〉、阪急阪神ホテルズ〈最大331,586件〉、テレビ東京〈件数精査中〉も公表）。
- サービスの再開時期。

### 関係しそうな既知の手口

- （考察）多くの企業が共通で使うSaaSが侵害されると、1社の事故が利用企業全体の事故になる。国内ではメール配信のアララ（[アララ メッセージ ― 不正アクセスで配信リストのメールアドレスが流出](https://color4pen.github.io/security-notes/notes/2026-10-29-arara-message-mail-delivery-3m-addresses-leak/)）の件で利用企業・自治体の公表が続いており、認証基盤prismatixの件ではギフティが主要機能を止めた（[ギフティ「giftee」 ― 認証基盤への不正アクセスで主要機能を停止](https://color4pen.github.io/security-notes/notes/2026-11-12-giftee-prismatix-auth-service-unauthorized-access/)）。KARTEの件との関係は公表されていない。

## 発表内容の整理

**事実（適時開示とステータスページによる）**

| 項目 | 内容 |
| --- | --- |
| 対象 | KARTEを利用する全プロジェクト |
| 停止した機能 | Web・アプリの計測、接客の配信、管理画面、チャット、KARTE Message、KARTE Datahub、API v2 など（ステータスページでは全項目がMajor Outage） |
| 処理中の影響 | 一括メール配信は途中で停止の場合あり。Datahubのデータ連携は失敗の場合あり |
| 情報 | 外部に漏えいした可能性のある情報を確認し、該当顧客にメールで連絡（11月13日23時35分）。【2026-11-17追記】11月16日、KARTEアカウントのメールアドレス79,249件、外部連携用認証情報、利用企業の取り込みデータの一部の漏えいを確認 |
| 原因 | 【2026-11-17追記】サーバーの脆弱性悪用による接続用認証情報の窃取、データの読み出し、アカウント乗っ取りによる管理画面への不正アクセス |
| 再開 | 未定 |

**考察**

- KARTEは利用企業のWebサイトやアプリにタグやSDKとして組み込まれ、訪問者の行動データを集める。サービス全体を止める判断は、侵害が特定の顧客環境ではなく共通基盤に及んだ可能性を示すが、公式には範囲が示されていない。
- 「該当のお客様」はプレイドの顧客、つまり利用企業を指すと読める。利用企業がエンドユーザーにどう説明するかは、漏えいした情報の種類次第で、今後の利用企業側の発表を見る必要がある。
- タグ配信型のサービスでは、配信基盤が乗っ取られるとサイト上で任意のスクリプトが動く恐れがある。全機能の停止はその経路を断つ意味もあると考えられるが、配信の改ざんがあったかどうかは公表されていない。

## 利用者・運用者がいまできること

- 利用企業：プレイドからの連絡メールの有無を確認する。KARTE Message・Datahubで途中停止したジョブを洗い出し、再開後の二重配信や欠損に備える。
- 利用企業：プレイドは、KARTEと外部サービスとの連携用認証情報（シークレットキー、アクセストークン等）の無効化を依頼している（11月15日16時01分の更新）。連携先ごとに無効化と再発行を進め、無効化前の期間に不審な利用がないかを連携先のログで確認する。
- 利用企業：サイトに埋め込んだKARTEタグの停止・削除の手順を確認しておく（再開時の挙動を含む）。
