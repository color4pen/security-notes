# 国税庁「e-Tax」 ― 不審な通信で停止、プログラムの一部が流出

## 要点

### 発表された事実

- 国税庁は2026年11月4日にe-Taxで不審な通信を検知し、確認のため機器メンテナンスを実施した。必要な対応と安全性の確認が完了したとして利用を再開し、「納税者の情報は漏えいしていないことを確認」したと告知した（[e-Tax 再開のお知らせ](https://www.e-tax.nta.go.jp/topics/2026/topics_20261104_mentenansu.htm)）。
- e-Taxは4日昼ごろから中断し、同日19時に不審な通信の検知を告知した。再開は5日11時（[ITmedia NEWS](https://www.itmedia.co.jp/news/article/2611/05/2000002897/)）。
- 同庁によると、システムを止めた際に、e-Taxを動かすためのプログラムの一部がコピーされ外部に流出する被害が出ていた。担当者は、システム上の機微な情報や納税者情報の流出はないと説明した（[時事通信](https://www.jiji.com/jc/article?g=soc&k=2026110500500)）。
- 申告期限の一律延長などは予定していない（時事通信）。

### わかっていないこと

- 不審な通信の内容と、プログラムの一部をコピーされた経路・手口。
- 流出したプログラムの範囲と、その中に設定値や接続先など悪用につながる情報が含まれていたか。
- 「機微な情報」に何を含めて判断したのか。
- 流出したプログラムを使った追加の攻撃への対策（修正・設定変更など）。

### 関係しそうな既知の手口

- （考察）ソースコードやプログラムが流出すると、攻撃者は内部の処理を読んで新しい弱点を探しやすくなる。直接の個人情報漏えいがなくても、後日の攻撃の準備材料になりうる。

## 概要

- 再開のお知らせは「納税者の情報は漏えいしていない」とだけ書いており、プログラムの一部流出は報道を通じて説明されている（[e-Tax](https://www.e-tax.nta.go.jp/topics/2026/topics_20261104_mentenansu.htm)、[時事通信](https://www.jiji.com/jc/article?g=soc&k=2026110500500)）。
- 同庁担当者は「多層的なセキュリティー対策を構築していた中で、一部の情報が漏えいしたのは遺憾」と述べた（時事通信）。

> この記事では、公式発表・報道で確認できた内容を「事実」、筆者の推測や意見を「考察」として分けて書いています。確認できなかった情報は書いていません。

## 発表内容の整理

**事実**

| 項目 | 内容 |
| --- | --- |
| 対象 | 国税電子申告・納税システム（e-Tax） |
| きっかけ | 11月4日に外部からの不審な通信を検知 |
| 停止 | 11月4日昼ごろ〜11月5日11時 |
| 流出 | e-Taxを動かすプログラムの一部（同庁の説明として報道） |
| 流出していない | 納税者情報、システム上の機微な情報（同庁の説明） |
| 申告期限 | 一律延長の予定なし |

出典：[e-Tax「e-Tax再開のお知らせ」（2026-11-04掲載、11-05更新）](https://www.e-tax.nta.go.jp/topics/2026/topics_20261104_mentenansu.htm)、[時事通信（2026-11-05）](https://www.jiji.com/jc/article?g=soc&k=2026110500500)、[ITmedia NEWS（2026-11-05）](https://www.itmedia.co.jp/news/article/2611/05/2000002897/)

**考察**

- 公式告知は再開と納税者情報の非漏えいに絞られ、プログラム流出は取材への回答として出ている。流出の範囲と影響評価は、公式の文書で示されるのが望ましい。
- 約1日で再開できたのは、侵入範囲が限られていたと判断できたためとみられるが、判断の根拠は公表されていない。

## 関係しそうな既知の手口

**事実**

- 不審な通信の手口は公表されていない。

**考察**

- 公開サーバー上のプログラムを読み出される典型は、パストラバーサルや設定不備によるファイル取得、管理用の経路への不正ログインなどである。本件がどれに当たるかは分からない。

## 利用者・運用者がいまできること

- 利用者：e-Taxや国税庁をかたるメールやSMSのリンクから手続きをしない。手続きはブックマークした公式サイトから行う。
- 運用者：公開サーバー上のプログラムや設定ファイルが外部から取得できる経路がないか、ソースコード流出を前提に秘密情報（鍵・接続情報）がコードに埋め込まれていないかを確認する。
