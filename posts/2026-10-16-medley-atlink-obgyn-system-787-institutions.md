# メドレー「アットリンク」 ― 産婦人科向け業務支援システムに不正アクセス、患者等の個人情報漏えいの可能性、最大787医療機関

## 要点

### 発表された事実

- 株式会社メドレーは2026年10月15日、医療機関業務支援システム「@link（アットリンク）」、患者向けアプリ「アットリンクアプリ」及び周辺サービス（以下「アットリンク等」）のシステムに対する第三者による不正アクセスを確認したと適時開示した（[メドレー適時開示](https://www.nikkei.com/markets/ir/irftp/data/tdnr/tdnetg3/20261015/g6hgc7/140120261014550839.pdf)、[お知らせ](https://www.medley.jp/notice/20161015.html)）。
- 2026年10月11日、外部の専門機関から第三者による不正アクセスの可能性があるとの情報提供を受けて調査を開始し、不正アクセスを確認。被害の拡大防止と更なる調査のため、同月14日深夜にアットリンク等の提供を一時停止した（適時開示）。
- アットリンク等に登録された患者等の個人情報が外部に漏えいした可能性がある。漏えいの有無及びその範囲（漏えいした可能性のある情報の項目、対象となる医療機関）は、外部の専門機関の協力を得て調査中。漏えいの対象となる可能性のある医療機関は、最大でアットリンク等を利用している全医療機関（787件）（適時開示）。
- 個人情報保護委員会への報告と警察への相談を行っている。サービス再開の見通しは調査結果を踏まえて改めて知らせる（適時開示、[アットリンクサービスサイト](https://at-link.net/?p=3237)）。
- 2026年12月期の連結業績への影響は軽微と見込む（適時開示）。
- 【2026-10-17追記】メドレーは10月16日19時時点の更新で、個人情報への影響について対象となる情報の項目と医療機関の範囲を確認・精査中とし、アットリンクはオンプレミス型とクラウド型のシステムが混在しているため、確認に当初の想定以上の時間がかかっていると説明した。今週末から週明けにかけて、項目と医療機関の範囲を概ね特定できる見通し。報告先として個人情報保護委員会、厚生労働省、警察を挙げた。サービス再開の見通しは10月19日（月）中に改めて知らせる（[アットリンクサービスサイト](https://at-link.net/?p=3237)）。

### わかったこと

- 【2026-10-17】漏えい項目と対象医療機関の範囲は、「今週末から週明けにかけて」概ね特定できる見通し。オンプレミス型とクラウド型が混在していることが精査に時間がかかる理由とされた。再開見通しは10月19日中に案内予定（[アットリンクサービスサイト](https://at-link.net/?p=3237)、10月16日19時時点）。

### わかっていないこと

- 漏えいの有無の確定、および漏えいした情報の項目・件数
- 対象となる医療機関の確定（787件は上限＝利用全機関）
- 侵入経路・原因、不正アクセスの開始時期（情報提供日は10月11日、発生日は未公表）
- サービス再開の見通し（【2026-10-17追記】10月19日中に見通しを案内予定）
- 患者数（787は機関数であり、患者数・漏えい件数ではない）

### 関係しそうな既知の手口

- （考察）医療機関向けSaaSに患者の連絡先・問診・接種履歴などが集約されているため、単一の基盤侵害が多数施設に波及し得る構造は、コミューン「Commune」の署名鍵侵害（多数コミュニティに影響、[記事](/security-notes/notes/2026-10-10-commune-community-platform-signing-key-307k-members/)）やTEMAIRAZU（多数宿泊施設の予約情報、[記事](/security-notes/notes/2026-10-12-temairazu-site-controller-4-45m-guests-phishing/)）と「共通基盤のリスク」という点で似ている。本件の経路は未公表であり、同型かどうかはわからない。

## 概要

- 産婦人科向けクラウドのアットリンクが不正アクセスを受け、患者等の個人情報が漏えいした可能性があり、最大787の利用医療機関が影響し得るとしてサービスが一時停止された。
- 漏えいの有無・項目・対象施設はまだ調査中で、件数や患者数は公表されていない。
- 停止の影響は予約だけでなく、デジタル診察券・受付機・呼び出し・エコー関連コンテンツなど院内運用にも及んでいる。

## 発表内容の整理

**事実（メドレー適時開示・サービスサイト）**

| 項目 | 内容 |
| --- | --- |
| 対象サービス | 医療機関業務支援システム「@link（アットリンク）」、患者向けアプリ「アットリンクアプリ」及び周辺サービス |
| 利用分野 | 主に産婦人科。予約・受付、入院・出産の管理などに使う（[ITmedia NEWS](https://www.itmedia.co.jp/news/article/2610/15/2000002293/)） |
| 影響し得る医療機関 | 最大787件（利用全機関）。対象施設は調査中 |
| 漏えいの可能性 | 登録された患者等の個人情報。有無・項目は調査中 |
| アプリが扱う情報の例（漏えい確定ではない） | ITmedia NEWSによると、アットリンクアプリでは氏名、性別、生年月日、住所、電話番号、メールアドレス、問診の回答やワクチン接種履歴などを扱っている |
| 停止中の主な機能（サービスサイト 10/15 16時時点） | 医療機関向け：予約受付・患者管理、デジタル診察券チェックイン、受付機、デジタルサイネージ呼出、オンライン決済、問診、EchoDiary、Wovie 等。患者向け：アプリ・WEB予約、デジタル診察券、オンライン決済、問診、マタニティダイアリー、Echo Diary、DearBaby、Wovie 等 |
| 関係機関 | 個人情報保護委員会へ報告、警察へ相談 |
| 再開 | 調査結果を踏まえて改めて知らせる |
| 問い合わせ | at-link@medley.jp / [問い合わせフォーム](https://at-link.net/contact/) |

**考察**

787という数字は「漏えい件数」ではなく「影響し得る医療機関の上限」である。適時開示も「最大で、アットリンク等を利用している全医療機関（787件）」と書いており、患者数や実漏えい件数はまだ出ていない。医療・妊娠・出産に関わる情報が扱われるサービスだけに、漏えいが確認された場合の機微性は高い一方、現時点では「可能性」段階にとどまる（考察）。

サービス停止自体が、全国の導入院の予約・受付・呼び出しに波及している。piyologは、自院サイトで停止を告知した医療機関を25院挙げ、受付機チェックインや番号呼び出し、4Dエコー撮影の一時停止など、予約以外の影響も整理している（[piyolog](https://piyolog.hatenadiary.jp/entry/2026/10/15/065625)）。クラウド型の業務基盤が止まると、診療そのものより「患者との接点のデジタル層」が一斉に落ちる、という構造が見える。

アットリンクは2001年に提供開始され、提供元だったオフショアは2024年10月にメドレーグループ入り、2025年4月にメドレーが吸収合併した、とpiyologがメドレーのnote等を基にまとめている（同）。長年運用されてきた医療向け基盤が、グループ再編後も広い導入面を持ったまま攻撃面になった可能性があるが、経路との因果は公表されていない。

## 関係しそうな既知の手口

**事実（既知の知見・同種事例）**

- 複数の顧客組織が同じSaaS基盤を使う国内事例として、コミューン「Commune」では全コミュニティ共通のログイン用署名鍵が奪われ多数サービスに影響し（[記事](/security-notes/notes/2026-10-10-commune-community-platform-signing-key-307k-members/)）、手間いらずのTEMAIRAZUでは宿泊予約管理システムへの不正アクセスで最大約445万人分の予約情報に影響した（[記事](/security-notes/notes/2026-10-12-temairazu-site-controller-4-45m-guests-phishing/)）。
- 医療従事者向け会員DBの委託先侵害として、旭化成セラピューティクス「Pharma DIGITAL」では医療従事者最大約51.4万人分が閲覧・取得の可能性とされた（[記事](/security-notes/notes/2026-10-07-asahi-kasei-pharma-digital-vendor-breach/)）。本件は患者側の情報が主題であり、対象は異なる。

**考察**

- **「最大＝全利用機関」は、テナント分離や侵害範囲の切り分けがまだ終わっていない合図**：漏えいが一部機関に限れるのか、基盤全体なのかが分かっていない段階では、事業者は上限を全件とせざるを得ない。
- **医療SaaSは「止める判断」と「診療継続」の両立が難しい**：10月11日の情報提供から14日深夜の停止まで数日空いているのは、適時開示が言うとおり暫定支援を挟んだためで、すぐに落とすと院の予約・受付が止まる。その間の追加侵害リスクと、停止による現場負荷のトレードオフが、この種の事案では繰り返し現れる（考察）。

## 利用者・運用者がいまできること

**事実（発表・案内に基づく）**

- 新規予約・予約変更は、利用先の医療機関へ直接問い合わせる（サービスサイト）。
- アプリに関する問い合わせは医療機関ではなく、at-link@medley.jp または問い合わせフォームへ（同）。
- メドレーやアットリンクを名乗る不審なメール・SMS・電話に注意する。パスワードやクレジットカード情報を尋ねることはない、とする案内が医療機関経由で出ている（piyologが整理した患者向け案内）。

**考察（患者向け）**

- 漏えいの有無は未確定でも、予約や出産関連の連絡を装った詐欺が増える局面になり得る。医療機関への確認は、公式サイトや診察券に載っている電話番号に自分からかける。
- 問診や接種履歴など機微情報がアプリに入っている場合、続報で漏えい項目が公表されたら、その内容に応じて関係機関・医療機関の案内に従う。

**考察（医療機関・運用者向け）**

- 予約一覧のオフライン運用、電話予約への切替、呼び出しの代替手順を、ベンダー提供の簡易マニュアルと合わせて維持する。
- ベンダーからの「復旧」「パスワード再設定」「振込」を装うメールを、院内でも疑う手順を共有する。
- 自院が扱う患者データの委託先・SaaS一覧と、インシデント時の停止・通知フローを再確認する。
