# テレビ東京ダイレクト ― 不正アクセスで通販サイト「テレ東マート」を閉鎖

## 要点

### 発表された事実

- テレビ東京ダイレクトが運営する通販サイト「テレ東マート」で第三者による不正アクセスが確認され、2026年11月2日午前3時53分にサービスを緊急停止（一時閉鎖）した。発表はテレビ東京、BSテレビ東京、テレビ東京ダイレクトの3社連名（[3社の発表](https://www.bs-tvtokyo.co.jp/company/press/pdf/20261102.pdf)）。
- 現時点で個人情報の漏えいは確認されておらず、クレジットカード情報の漏えいも確認されていない。影響範囲と侵入経路を調査中（同）。
- 再開時期は、安全性が確認され次第案内する。番組で紹介した商品はコールセンター（0120-88-0488）で注文できる（同）。

### わかっていないこと

- 不正アクセスに気づいた日時と、不正アクセスの期間
- 侵入経路と、サイト内のどのデータに触れられた可能性があるか
- 個人情報・カード情報の漏えいの有無（調査結果）
- サイトの再開時期

### 関係しそうな既知の手口

- ECサイトへの不正アクセスでは、決済画面の改ざんによるカード情報の窃取が国内で繰り返し起きてきた。今回カード情報の漏えいは確認されていないとされ、手口も公表されていない（考察）。

## 概要

- テレビ通販の商品を扱う「テレ東マート」が、不正アクセスの確認を受けて未明にサイトを止めた。
- 発表時点では漏えいは確認されておらず、調査中の段階。
- 漏えいが確認される前にサイトを止め、電話注文の窓口を残した対応が発表の中心になっている。

> この記事では、公式発表・報道で確認できた内容を「事実」、筆者の推測や意見を「考察」として分けて書いています。確認できなかった情報は書いていません。

## 発表内容の整理

**事実（3社の発表による）**

| 項目 | 内容 |
| --- | --- |
| 対象 | 通販サイト「テレ東マート」（運営：テレビ東京ダイレクト） |
| 対応 | 2026年11月2日午前3時53分にサービスを緊急停止（一時閉鎖） |
| 個人情報 | 現時点で漏えいは確認されていない |
| クレジットカード情報 | 現時点で漏えいは確認されていない |
| 調査 | 影響範囲と侵入経路を調査中 |
| 再開 | 安全性が確認され次第、改めて案内 |

- 問い合わせ窓口は、テレビ東京ダイレクトお客様対応窓口（0120-120-950、9時〜18時、tv-tokyoshop_cs@txshop.jp）（同）。
- 身に覚えのない送信元からの不審なメール・SMS・メッセージに注意するよう呼びかけている（同）。

**考察**

「漏えいは確認されていない」は「漏えいしていない」とは違い、調査の途中であることを示す表現だ。過去の国内EC事例でも、初報で漏えい未確認とされ、後の調査で範囲が判明した例はある。続報で、不正アクセスの期間と、決済画面やデータベースに手が入っていたかが示されるかが焦点になる（考察）。

## 関係しそうな既知の手口

**事実（既知の知見）**

- JPCERT/CCは2026年10月の注意喚起で、国内組織で不正アクセスによる個人情報の漏えいが相次いでいるとして、既知の脆弱性の探索・悪用や、環境設定ファイル・バックアップファイルの窃取などを手口として挙げている（[JPCERT/CC 注意喚起](https://www.jpcert.or.jp/at/2026/at260030.html)）。

**考察**

テレ東マートの件が、これらの手口と同じかどうかは発表からはわからない（考察）。

## 利用者・運用者がいまできること

- テレ東マートで使ったクレジットカードの利用明細に、心当たりのない請求がないか確認する。
- テレ東マートと同じパスワードを他のサービスで使っている場合は、念のため変更しておく（発表は変更を求めていない）。
- 「再開しました」「返金のご案内」などのメール・SMSのリンクは開かず、テレビ東京の公式サイトで確認する。
