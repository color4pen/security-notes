# エイコー ― 一部システムに不正アクセス、ランサムウェア被害

## 要点

### 発表された事実

- エイコーは2026年11月13日、11月9日に同社の一部システムで第三者による不正アクセスを受け、ランサムウェアによる被害が発生したことを確認したと発表した（[エイコー 11月13日発表](https://www.eicoh.com/news/detail/127)）。
- 関係機関・専門家と連携して被害状況の調査と復旧を進めている。情報の外部流出の有無と影響範囲は調査中（同）。
- 同社を装ったメールなどが送られる可能性があるとし、同社からメールなどで振込先の変更を依頼することはないと案内している。専用の問い合わせ窓口（ランサムウェア対応緊急対策チーム）を設けた（同）。
- ランサムウェア被害の掲載を追跡するIncidentLogは、攻撃グループ「The Gentlemen」が自らのリークサイトに「EiCOh」（eicoh.com）を載せたのを2026年11月11日（UTC）に観測したと記録している。同サイトは企業の公表と同じ事案かどうかは確認できていないとしている（[IncidentLog](https://incidentlog.jp/claims/the-gentlemen-20261111-e068fd)）。

### わかっていないこと

- 情報の外部流出の有無と、流出した場合の範囲（顧客・取引先の情報を含むか）。
- 影響を受けたシステムの名前と範囲、業務への影響。
- 侵入経路とランサムウェアの種類。
- リークサイトへの掲載が、公表された事案と同じものかどうか。

### 関係しそうな既知の手口

- ランサムウェアの被害を受けた企業の名をかたり、請求書の振込先変更を求めるビジネスメール詐欺は、取引先情報やメールが持ち出された場合に起こりやすい。エイコーの注意喚起はこれを防ぐためのもので、偽のメールが実際に送られたとは発表していない。
- （考察）リークサイトへの掲載（11月11日 UTC）が事実であれば、検知（11月9日）から2日ほどで攻撃側が名前を出したことになり、データの持ち出しを伴う二重恐喝の典型的な流れと一致する。ただし掲載は攻撃側の主張であり、確認されていない。

> この記事では、公式発表・報道で確認できた内容を「事実」、筆者の推測や意見を「考察」として分けて書いています。確認できなかった情報は書いていません。

## 発表内容の整理

**事実（エイコーの11月13日の発表による）**

| 項目 | 内容 |
| --- | --- |
| 確認日 | 2026年11月9日 |
| 事象 | 一部システムへの第三者の不正アクセス、ランサムウェア被害 |
| 情報流出 | 有無を調査中 |
| 影響範囲 | 調査中 |
| 取引先への案内 | 同社を装う連絡に注意、メールで振込先変更を依頼することはない |

**考察**

- 第1報は件数やシステム名を含まない短いものだが、振込先変更の詐欺に先回りして触れている点は、取引先が多いBtoB企業として実際的な対応といえる。
- 情報流出の有無が調査中のまま、攻撃グループ側の掲載が報告されている。続報では、持ち出しの有無と、取引先の情報が含まれるかが焦点になる。

## 利用者・運用者がいまできること

- エイコーの取引先：振込先の変更や支払いの催促がメールで届いたら、返信ではなく、契約書や社内台帳に登録済みの電話番号でエイコーの担当者に確かめる。
- 運用者：取引先がランサムウェア被害を公表したときは、その取引先からのメールの添付ファイルや振込先の変更依頼を、しばらくの間は二重に確認する運用を決めておく。
