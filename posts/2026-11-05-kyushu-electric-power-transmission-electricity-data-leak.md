# 九州電力送配電 ― 不正アクセスで電力量情報が漏えいした可能性

## 要点

### 発表された事実

- 九州電力送配電は、一部システムへの不正アクセスにより、保有する電力量情報の一部（4,139件）が社外に漏えいした可能性があると公表した（[九州電力送配電](https://www.kyuden.co.jp/td/press/2026/261105.html)）。
- 漏えいの可能性がある情報は、使用電力量（月間値・30分値）、需要側の供給地点特定番号、売電電力量（月間値・30分値）、発電側の受電地点特定番号（同）。
- お客さま名、住所、電話番号、メールアドレス、口座情報など契約情報は含まれない（同）。
- 当該システムはネットワークから切り離されており、電力量・料金照会サービスを停止中。電力の安定供給に支障はない（同）。

### わかっていないこと

- 侵入経路と原因。
- 電力量・料金照会サービスの復旧時期。
- 漏えいの可能性が、確定した持ち出しなのかログ上の痕跡に基づく推定なのかの詳細。

### 関係しそうな既知の手口

- （考察）契約者の氏名・住所は含まれない一方、地点特定番号と電力量の組み合わせは、電力小売や発電側の業務データとして扱われることがあり、利用者向けフィッシングというより取引先や業務関係者へのなりすましに使われうる。

## 概要

- 2026年10月30日、システムで不自然なエラーを検知し、調査の結果不正アクセスの可能性があると判断して当該システムを緊急停止した（[九州電力送配電](https://www.kyuden.co.jp/td/press/2026/261105.html)）。
- サーバのログ調査で、一部情報が社外に漏えいした可能性があると判明した（同）。
- 11月2日に個人情報保護委員会および監督官庁へ報告済み。対象のお客さまには11月中旬目途で個別にお知らせする（同）。

## 発表内容の整理

**事実（九州電力送配電の発表による）**

| 項目 | 内容 |
| --- | --- |
| 件数 | 4,139件 |
| 漏えいの可能性がある情報 | 使用電力量（月間値・30分値）、需要側の供給地点特定番号、売電電力量（月間値・30分値）、発電側の受電地点特定番号 |
| 含まれない情報 | お客さま名、住所、電話番号、メールアドレス、口座情報などの契約情報 |
| 停止中のサービス | 電力量・料金照会サービス（離島のお客さま、および九州本土で同社と売電契約をしているお客さまのうち会員登録したお客さま向け） |
| 復旧見込 | 検討中 |
| 電力供給 | 安定供給に支障なし |

出典：[九州電力送配電](https://www.kyuden.co.jp/td/press/2026/261105.html)

**考察**

- 契約情報そのものは含まれないと明記されている一方、地点特定番号は電力小売・発電の業務識別子として使われるため、影響の受け方は一般消費者向け漏えいとは異なる可能性がある。

## 関係しそうな既知の手口

**事実**

- 侵入経路や技術的要因は公表されていない（[九州電力送配電](https://www.kyuden.co.jp/td/press/2026/261105.html)）。

**考察**

- 重要インフラ事業者の照会系システムは、インターネット公開の会員サービスや業務連携の接点が入口になりやすい。今回どの経路だったかは続報を待つ必要がある。

## 利用者・運用者がいまできること

- 電力量・料金照会サービスが使えない間は、同社の案内に従い問い合わせ窓口を利用する。
- 同社や電力小売を装った不審な連絡に注意する。
- 運用者は、電力量照会など顧客向けWebと、内部の計量・売電管理系の境界とログ監視を見直す。
