# ヤマダデンキ ― リフォーム管理システムに不正アクセス

## 要点

### 発表された事実

- ヤマダデンキは2026年11月13日、同社のリフォーム管理システムが第三者からの不正アクセスを受けたことが判明したと発表した（[ヤマダデンキ 11月13日発表](https://www.yamada-denki.jp/information/pdf/261113_1.pdf)）。
- 11月12日に不正アクセスを確認し、ただちに外部からのアクセスを遮断して詳細調査を始めた（同）。
- 影響を受けた可能性があるのは、同システムに登録された顧客の氏名、住所、電話番号、その他リフォーム実施履歴および見積データ等の営業記録で、最大350万件（同）。
- マイナンバーとクレジットカード情報は含まれない。店頭やECサイトでの家電購入情報など、リフォーム以外の情報は対象外（同）。
- 顧客情報の外部への流出は調査中としている（同）。
- 同社は別件として、10月22日16時13分ごろから「ヤマダビデオ」と「スマホゴールド会員」の各種手続き画面を、外部からの不正アクセスを確認したため停止したと10月23日に発表している（[ヤマダデンキ 10月23日発表](https://www.yamada-denki.jp/information/pdf/261023_3.pdf)）。

### わかっていないこと

- 外部への流出の有無と、件数の確定値（「最大350万件」が人数か記録数か）。
- 不正アクセスの経路、原因、始まった時期。
- 10月22日の手続き画面への不正アクセスとの関係。
- 対象者への個別連絡を行うかどうか。

### 関係しそうな既知の手口

- （考察）侵入経路は公表されていない。国内では10月以降、業務システムや管理画面への不正アクセスの公表が相次いでおり、JPCERT/CC・NCO・IPAが注意喚起を出している（[相次ぐ不正アクセスにJPCERT/CC・NCO・IPAが一斉に注意喚起](https://color4pen.github.io/security-notes/notes/2026-10-11-jpcert-nco-ipa-alerts-domestic-breach-wave/)）。本件がその一連の攻撃に含まれるかはわからない。

## 発表内容の整理

**事実（ヤマダデンキの11月13日の発表による）**

| 項目 | 内容 |
| --- | --- |
| 対象システム | リフォーム管理システム |
| 確認日 | 11月12日（ただちに外部アクセスを遮断） |
| 影響の可能性がある情報 | 氏名、住所、電話番号、リフォーム実施履歴・見積データ等の営業記録 |
| 件数 | 最大350万件 |
| 対象外 | マイナンバー、クレジットカード情報、家電購入情報などリフォーム以外の情報 |
| 流出 | 調査中 |

**考察**

- リフォームの見積や実施履歴は、住所と住まいの状況が結びついた情報で、点検商法や工事業者を装う電話・訪問に使われやすい種類のデータといえる。漏えいが確定した場合、メールよりも電話や訪問による二次被害に注意が要る。
- 確認の翌日に件数の上限まで示して公表しており、初動は早い。一方、流出の有無や経路はまだ示されていない。

## 利用者・運用者がいまできること

- 利用者：ヤマダデンキでリフォームを依頼した、または見積を取ったことがある人は、同社を名乗る電話・訪問・SMSに注意する。同社はメールや電話でパスワードや暗証番号を尋ねないとしている。
- 利用者：「点検」「追加工事」などを持ちかける心当たりのない連絡は、同社の窓口に直接確認する。
- 運用者：営業・見積の管理システムが外部から接続できる場合、接続元の制限と多要素認証の有無を確認する。
