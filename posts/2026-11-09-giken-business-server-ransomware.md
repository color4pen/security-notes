# 技研製作所 ― 業務用サーバーにランサムウェアを含む不正アクセス

## 要点

### 発表された事実

- 技研製作所は2026年11月9日、業務用サーバー1台がランサムウェアを含む外部からの不正アクセスを受けたと第1報で発表した（[技研製作所](https://www.giken.com/ja/news/notices/notice_20261109/)）。
- 11月5日にサーバーの異常を確認し、6日に外部からの接続を遮断した（同）。
- サーバーには、ユーザーと指定工場の担当者（海外企業を含む）の氏名・会社名・部署・役職・メールアドレス・電話番号など、グループ従業員の氏名・メールアドレス・社員番号など、顧客支援システムのログインIDとパスワード（暗号化した形式）が保存されていた。対象は約3,200名（同）。
- 情報が外部に送信された痕跡は確認されていないが、窃取の可能性を否定できないため公表した。クレジットカード情報、銀行口座情報、マイナンバーは含まれない（同）。
- 再発防止として、サーバーの入れ替え、外部からの接続とログイン認証の見直し、監視の強化を挙げている（同）。

### わかっていないこと

- 侵入経路と、ランサムウェアの種類・攻撃者。
- 外部送信の有無についての調査結果。
- 顧客支援システムのパスワードの具体的な保存方式と、利用者にパスワード変更を求めるか。
- このサーバー以外への影響。

### 関係しそうな既知の手口

- （考察）再発防止策に「外部からの接続とログイン認証の見直し」が入っており、外部から到達できる接続口の認証が突かれた可能性はあるが、同社は経路を明らかにしていない。国内ではネットワーク機器を経由して侵入されランサムウェア被害に至った例もある（例：[アンビションDXホールディングス](https://color4pen.github.io/security-notes/notes/2026-10-21-ambition-dx-ransomware-final-report-140k-files-580k/)）。

## 概要

- 対象者には個別に連絡し、連絡がつかない人にはこの公表で通知に代えるとしている（[技研製作所](https://www.giken.com/ja/news/notices/notice_20261109/)）。
- 問い合わせはメール窓口で受け付けている（同）。

## 発表内容の整理

**事実（技研製作所の第1報による）**

| 項目 | 内容 |
| --- | --- |
| 対象 | 業務用サーバー1台 |
| 攻撃 | ランサムウェアを含む外部からの不正アクセス |
| 社外の対象 | ユーザー・指定工場の担当者（海外企業を含む）：氏名、会社名、部署・役職、メールアドレス、電話番号など |
| 社内の対象 | グループ従業員：氏名、メールアドレス、社員番号など |
| 認証情報 | 顧客支援システムのログインIDとパスワード（暗号化した形式） |
| 人数 | 約3,200名 |
| 含まれない | クレジットカード情報、銀行口座情報、マイナンバー |
| 外部送信 | 痕跡は未確認 |

出典：[技研製作所「当社サーバーへの不正アクセスによる個人情報漏えいのおそれに関するお知らせとお詫び（第1報）」（2026-11-09）](https://www.giken.com/ja/news/notices/notice_20261109/)

**考察**

- 顧客支援システムのIDとパスワードが同じサーバーに置かれていた点が気になる。「暗号化した形式」が復号できる方式なら、鍵の置き場所しだいで顧客支援システムへの不正ログインにつながる。続報でパスワード変更の案内があるかを確認したい。
- 取引先の担当者名と所属がそろうと、取引先を装ったメールが作りやすくなる。海外の取引先も対象になっている。

## 関係しそうな既知の手口

**事実**

- 同社は侵入経路を公表していない（[技研製作所](https://www.giken.com/ja/news/notices/notice_20261109/)）。

**考察**

- 外部送信の痕跡がなくても、暗号化を伴う攻撃では事前の持ち出しが後から判明することがある。通信ログの保存期間が調査の結論を左右する。

## 利用者・運用者がいまできること

- 取引先担当者：技研製作所を名乗る、振込先変更や添付ファイルを開かせるメールに注意する。顧客支援システムのパスワードを他で使い回している場合は変える。
- 運用者：社外から到達できる接続口（VPN・リモートデスクトップ）の多要素認証と更新状況を点検する。業務サーバーに別システムの認証情報を置かない。
