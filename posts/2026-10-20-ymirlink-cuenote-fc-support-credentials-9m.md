# ユミルリンク「Cuenote FC」 ― メール配信基盤の脆弱性からサポート担当者の認証情報を奪われ、専用ASPプラン5システムでメールアドレスを含む延べ約900万件が持ち出し

## 要点

### 発表された事実

- ユミルリンク株式会社は2026年10月19日、メール配信サービス「Cuenote FC」の一部サーバーシステムが外部から不正アクセスを受け、個人情報が外部に持ち出されたことを確認したと公表した（[Cuenote](https://www.cuenote.jp/information/news/unauthorizedaccess.html)、[TDnet開示](https://fs2.magicalir.net/tdnet/2026/4372/20261019553124.pdf)）。
- 10月16日（金）未明に担当者が不正アクセスに気づいた。アクセス記録から、(1)プログラムの脆弱性を突かれ、(2)同社のサポート・品質管理担当者のサービスへの認証情報を取得され、(3)不正プログラムを置かれてデータベースからデータを出力され、(4)その認証情報で他のシステムへの認証を試みられていたことを確認した（同）。
- 不正アクセスとデータの出力を確認したのは「Cuenote FC 専用ASPプラン」のうち合計5システムで、メールアドレスを含む情報が延べ約900万件出力されたと試算している（同。プラン名は19日19:05の更新版で追記）。
- 利用企業の山陽新聞社は、10月18日午後2時15分頃からメール配信サービス（ニュース速報・気象情報・列車遅延情報など）が止まっており、委託先がユミルリンクであること、自社の情報が対象に含まれるかは確認中であることを公表した（[山陽新聞社](https://c.sanyonews.jp/release/2026/10/20261019230413.html)）。

### わかったこと

- 【2026-10-20追記】山陽新聞社は10月20日12時19分の第3報で、ユミルリンクから「当社が利用している環境では情報漏えいは確認されていない」との連絡を受けたと発表した。10月18日午後2時15分頃から止まっているメール配信サービスは復旧に向けて準備中（[山陽新聞社 第3報](https://www.sanyonews.jp/article/2007490)）。山陽新聞社は対象の5システムには含まれていなかったとみられる（考察）。

- 【2026-10-21】10月20日には、Cuenote FCを使う他の組織も公表した。埼玉県は、スマート農業の情報サイト「ぷらっとさいたま -スマート農業導入ナビ-」を通じて取得した669者（法人は法人名・担当者名・メールアドレス・業種、個人は氏名・メールアドレス・業種）の個人情報が流出した可能性があると発表した。県の委託先のナレッジクライマーが使うメールマガジンシステムがユミルリンクのもので、同社から10月20日に報告を受けた。不正利用は確認されていない（[埼玉県](https://www.pref.saitama.lg.jp/a0903/news/page/news2026102001.html)）。NTTPCは、各種サービスのメール配信に使うCuenote FCについて、自社の顧客情報への影響は確認できていないが否定もできないとして、連絡先メールアドレス等の漏えいの可能性を公表した（[NTTPC](https://www.nttpc.co.jp/press/info/2026/10/202610201600.html)）。カクヤスは、飲食店向けメールマガジンに使っていた登録情報（飲食店名・社名・氏名・メールアドレス）が対象に含まれるとの情報は確認できていないとしつつ、注意喚起を始めた（[カクヤス](https://www.kakuyasu.co.jp/system/media_libraries/4791/file.pdf)）。かたばみも、影響を受けた可能性を否定できないと発表した（[かたばみ](https://www.katabami.co.jp/news/news_detail.php?nid=100000599)）。

- 【2026-10-21追記】大日本印刷（DNP）は10月21日、運営するハイブリッド型総合書店「honto」のメール配信委託先がユミルリンクで、同社のメール配信システムへの不正アクセスにより、同社サーバーに保存されていたhontoの顧客情報が漏えいした可能性があると発表した。10月19日にユミルリンクから報告を受けた。対象はhontoのメールマガジン配信を許諾している顧客の氏名・メールアドレス・システム内部の識別番号で、件数は調査中。パスワード・クレジットカード情報・購入履歴はメール配信システムに保有していない。DNPグループのシステムへの不正アクセスは確認されておらず、hontoと当該メール配信システムの連携は遮断した。二次被害は確認されていない（[大日本印刷](https://www.dnp.co.jp/securityincident20261021.pdf)）。

### わかっていないこと

- 突かれた「プログラムの脆弱性」が何か（自社開発部分か、使用しているソフトウェアか）
- 侵入が始まった時期と、データが出力されていた期間
- 対象の5システムがどの利用企業のものか、それぞれ何件か（【2026-10-21追記】ユミルリンクは一覧を出していない。埼玉県は委託先経由で669者が対象になり得ると発表したが、NTTPC・カクヤス・かたばみは自社分が含まれるか確認中。【2026-10-21夕方追記】大日本印刷は、ユミルリンクから「hontoの顧客情報が漏えいした可能性がある」と報告を受けたと発表したが、件数は調査中）
- メールアドレス以外に出力された項目（氏名・属性情報・配信本文など）と、重複を除いた人数
- サポート・品質管理担当者の認証情報による「他のシステムへの認証」の試みが成功したかどうか
- 専用ASPプラン以外のCuenoteのサービスに影響がないか

### 関係しそうな既知の手口

- （考察）提供会社の「サポート担当者の認証情報」は、多くの利用企業の環境に入れる共通の鍵になりやすい。10月には管理用アカウントの認証情報を奪われた楽天ドライブや、全コミュニティ共通の署名鍵を奪われたCommuneなど、運営側の強い権限を足がかりに被害が広がった事例が続いている。

## 概要

- メール配信のCuenote FCで、プログラムの脆弱性からサポート担当者の認証情報が奪われ、不正プログラムでデータベースのデータが持ち出された。
- 対象は専用ASPプランの5システムで、メールアドレスを含む延べ約900万件と試算されている。どの利用企業かは公表されていない。
- 利用企業側でもメール配信が止まり、自社の会員情報が含まれるかの確認が始まっている。

> この記事では、公式発表・報道で確認できた内容を「事実」、筆者の推測や意見を「考察」として分けて書いています。確認できなかった情報は書いていません。

## 発表内容の整理

**事実（ユミルリンクの第一報）**

| 項目 | 内容 |
| --- | --- |
| 対象サービス | メール配信サービス「Cuenote FC」の専用ASPプランのうち、合計5システム |
| 気づいた時期 | 2026年10月16日（金）未明 |
| 確認した手口 | プログラムの脆弱性 → サポート・品質管理担当者の認証情報の取得 → 不正プログラムの設置とデータベースからのデータ出力 → 同じ認証情報で他システムへの認証の試み |
| 件数 | メールアドレスを含む情報、延べ約900万件が出力されたと試算（詳細は調査中） |
| 対応 | サーバーの切り離し、脆弱性修正プログラムの作成・適用、他システムからのサポート・品質管理担当者情報の削除、不正プログラムの検知体制の整備、捜査機関への届出 |
| 今後 | 外部専門家の協力で詳細調査。2026年12月期の業績への影響は精査中 |
| 問い合わせ | 不正アクセス専用窓口 03-6820-0088（平日9時〜20時）、support@cuenote.ne.jp |

**事実（報道・利用企業）**

- ITmediaは、同社サイトによるとCuenoteシリーズから配信されるメール・SMSは月間89億通、システム契約数は2900を超えると伝えた（[ITmedia NEWS](https://www.itmedia.co.jp/news/article/2610/20/2000002409/)）。
- 山陽新聞社は、ニュース速報・気象情報・列車遅延情報・朝夕のニュースレター・記者セレクト・ファジアーノ速報の配信が止まっていること、自社の会員情報の漏えいは現時点で確認されていないことを案内した（山陽新聞社）。

**考察**

件数が「延べ」で示されている点に注意したい。5つのシステムで同じメールアドレスが重ねて数えられている可能性があり、900万人分という意味にはならない。一方で、配信基盤は利用企業から預かった配信先リストそのものを抱えているため、利用企業の数だけ「どこのサービスの会員か」がひも付いた情報になっている可能性がある（考察）。

山陽新聞社のメール配信は、ユミルリンクの公表より前の18日午後から止まっている。16日未明に気づいてサーバーを切り離した対応の影響が、利用企業側に先に「配信障害」として現れたと考えられる（考察。山陽新聞社の停止理由について、両社はそれ以上説明していない）。

## 関係しそうな既知の手口

**事実（既知の知見・同種事例）**

- 自治体の防災メールを載せた配信基盤「SpeeCAN RAIDEN」への不正アクセスでは、全国の自治体の利用者のメールアドレスと配信履歴の本文に漏えいの可能性が出た（[SpeeCAN RAIDENの記事](/security-notes/notes/2026-10-14-arcadia-speecan-raiden-municipal-disaster-mail-3-13m/)）。
- 楽天ドライブでは管理用アカウントの認証情報が奪われ、1万5382アカウント分の保存データが取得・閲覧された（[楽天ドライブの記事](/security-notes/notes/2026-10-08-rakuten-drive-admin-credential-stored-files-15k-accounts/)）。
- JPCERT/CCは10月の注意喚起で、既知の脆弱性の探索、API経由での不正な操作、Webシェル設置などの攻撃類型を示している（[各機関の注意喚起の記事](/security-notes/notes/2026-10-11-jpcert-nco-ipa-alerts-domestic-breach-wave/)）。

**考察**

- **サポート用の権限が横移動の道具になった**：ユミルリンクは、奪われたのが「サポート・品質管理担当者のサービスへの認証情報」で、それを使って他のシステムへの認証が試みられたと書いている。提供会社の担当者が障害対応のために各システムへ入れる仕組みは便利だが、1つ奪われれば複数の利用企業の環境に届く。「他システムからの担当者情報の削除」を対策に挙げていることからも、同じ担当者の情報が複数のシステムに登録されていたと読める（考察）。
- **専用プランでも共通の部品は残る**：対象は利用企業ごとに分かれているはずの「専用ASPプラン」だった。システムが分かれていても、同じプログラムの脆弱性と、共通のサポート用認証情報があれば、続けて複数のシステムに入れる（考察）。

## 利用者・運用者がいまできること

**事実（発表に基づく）**

- Cuenoteを使っている企業は、自社の契約が対象の5システムに含まれるかをユミルリンクの専用窓口で確認する（ユミルリンク）。
- 山陽新聞社は、同社や「さんデジ」をかたる不審なメールのURLをクリックせず削除するよう呼びかけている（山陽新聞社）。

**考察（利用者向け）**

- メールマガジンや通知を受け取っている企業から「配信停止」「お詫び」の案内が届いたら、メール内のリンクではなく公式サイトやアプリから内容を確かめる。配信先リストが漏れると、そのサービスを名乗るフィッシングが来やすくなる。

**考察（運用者向け）**

- 配信を委託している企業は、委託元として個人情報保護委員会への報告と本人への通知の要否を、ユミルリンクの回答を待ちながら準備しておく。代理店や制作会社経由でCuenoteを使っていないかも確認する。
- 自社が使うクラウドサービスについて、提供会社のサポート担当者が自社の環境へ入れる設定になっているか、その操作の記録を見られるかを確かめる。不要な常時アクセスは止めてもらう。
- 自社ドメインのSPF・DKIM・DMARCを確認し、自社をかたるメールが届きにくい状態にしておく。
