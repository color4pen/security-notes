# 電通デジタル「TONARIWA」 ― 管理アカウントに不正アクセス、情報漏えいの可能性

## 要点

### 発表された事実

- 電通デジタルは2026年11月11日、同社が提供するマーケティングプラットフォーム「TONARIWA」で第三者による不正アクセスを確認し、サービスを一時停止したと発表した。調査の過程で、一部の個人情報が外部に漏えいした可能性があることがわかった（[電通デジタル](https://www.dentsudigital.co.jp/news/updates/services/2026-1111-001111)）。
- 11月10日、TONARIWAのシステム基盤で使っている管理アカウントで、認証情報の漏えいに起因する不正アクセスと権限昇格（操作範囲の拡大）が行われていたことを確認した（同）。
- 漏えいした可能性があるのは、一部のクライアント企業が扱うエンドユーザーの個人情報（氏名、生年月日、連絡先等の属性情報）と、TONARIWA管理用アカウント情報（LINE公式アカウント連携用のアクセストークン等）。クレジットカード情報や金融機関口座情報は含まれていない。対象企業・件数・詳細な項目は特定作業中（同）。
- 悪用は確認されていないが、LINE公式アカウントの連携情報が含まれていた可能性があるため、第三者による不正なメッセージ配信等のリスクは排除できないとしている（同）。

### わかっていないこと

- 対象となるクライアント企業と件数、詳細なデータ項目。
- 管理アカウントの認証情報がどこから漏れたのか、権限昇格をどう行われたのか。
- 最初に侵入された日時と、持ち出された範囲。
- 連携トークンの再発行がどこまで済んだか、不正配信が起きたかどうか。
- サービス再開の時期。

### 関係しそうな既知の手口

- （考察）クラウド基盤の管理用の認証情報が漏れ、そこから権限を広げられる流れは、[Shippio](https://color4pen.github.io/security-notes/notes/2026-11-04-shippio-platform-internal-tool-credential-abuse/)や[iDA「MyBRANDS」](https://color4pen.github.io/security-notes/notes/2026-11-02-ida-mybrands-cloud-access-key-misuse/)と同じ型に見える。同じ攻撃者や同じ経路であることを示す情報はない。

## 概要

- TONARIWAは、企業のLINE公式アカウントと連携してメッセージ配信などを支援するサービス（[日本経済新聞](https://www.nikkei.com/article/DGXZQOUC11AHR0R11C26A1000000/)）。
- 被害を受けたのは電通デジタルのシステムだが、個人情報の持ち主は利用企業のエンドユーザーで、利用企業から見ると委託先での事故になる。

## 発表内容の整理

**事実（電通デジタルの11月11日の発表による）**

| 項目 | 内容 |
| --- | --- |
| 対象 | マーケティングプラットフォーム「TONARIWA」のシステム基盤 |
| 入口 | 管理アカウントの認証情報の漏えい（漏えい経路は未公表） |
| その後 | 権限昇格（操作範囲の拡大） |
| 漏えいの可能性 | 利用企業のエンドユーザーの氏名・生年月日・連絡先等、LINE公式アカウント連携用アクセストークン等 |
| 対象外 | クレジットカード情報、金融機関口座情報 |
| 対応 | 認証情報の失効、通信経路の遮断、全サーバー停止による隔離、フォレンジック調査会社の選定、利用企業への個別説明、連携トークンの再発行・切替 |

出典：[電通デジタル「当社が提供する「TONARIWA」における不正アクセスに伴う個人情報漏えいの可能性に関するお詫びとご報告」（2026-11-11）](https://www.dentsudigital.co.jp/news/updates/services/2026-1111-001111)

**考察**

- 個人情報より影響が読みにくいのは連携トークンのほうだ。LINE公式アカウントの配信権限が第三者に渡ると、利用者は「いつも使っている企業のアカウント」からの偽メッセージを受け取ることになり、通常のフィッシングより見分けにくい。発表がこのリスクを明記し、トークンの切替を進めているのはこのためと読める。
- トークンの切替は利用企業の他システムの連携にも関わるため、電通デジタルだけでは完了できない部分がある。発表でも利用企業側の作業が必要な事項を個別に案内するとしている。

## 利用者・運用者がいまできること

- 利用者：企業のLINE公式アカウントからの連絡でも、パスワードや決済情報の入力、送金を求める内容は、企業の公式サイトなど別の経路で確かめる。
- 利用企業：自社が対象か電通デジタルの案内を確認し、連携しているLINE公式アカウントの配信履歴・予約配信・管理者の変更に不審な点がないか点検する。
- 運用者一般：クラウド基盤の管理アカウントに多要素認証やアクセス元の制限がかかっているか、不要な強い権限が残っていないかを見直す。
