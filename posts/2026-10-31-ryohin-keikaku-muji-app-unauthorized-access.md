# 良品計画 ― MUJIアプリへの不正アクセスで顧客情報流出の可能性

## 要点

### 発表された事実

- 良品計画は2026年10月30日、無印良品の公式アプリ「MUJIアプリ」で、同社が保有する顧客情報の一部が外部に流出した可能性があると公表した（[良品計画](https://www.ryohin-keikaku.jp/news/articles/2026_1030_01)）。
- 流出した可能性があるのはメールアドレス、生年月日、性別。クレジットカード情報、氏名、住所、電話番号などは含まれない（同）。（【2026-11-04追記】第二報で訂正。ネットストア会員も対象で、一部は氏名・住所・電話番号、MUJI Cardのカード番号なども対象）
- 対象は最大約2,726万件で、退会した顧客の情報を含む（同）。
- 外部からの不正なアクセスを検知し、該当箇所へのアクセスの遮断と修正の適用を行った。ダークウェブなどへの流出や悪用の被害は確認されていない。アプリとネットストアは通常どおり使える（同）。

### わかったこと

- 【2026-11-04夕追記】良品計画は11月4日の第二報で、最大約2,726万件の対象には無印良品ネットストア会員（MUJIアプリを使っていない人を含む）も含まれ、一部の人は氏名・住所・電話番号も対象だったと訂正した。第一報で「含まれない」としていた項目が対象に加わった（[良品計画 第二報](https://www.ryohin-keikaku.jp/news/articles/2026_1104_02)）。
- 【2026-11-04夕追記】クレジットカード情報にもアクセスされた可能性がある。2021年7月以前は特典付与のためMUJI Card（クレディセゾン発行）のカード番号・MUJI Card ID・生年月日を取得しており、それが良品計画のシステムに残っていた（[良品計画 第二報](https://www.ryohin-keikaku.jp/news/articles/2026_1104_02)）。クレディセゾンによると対象は2000年10月〜2021年7月に入会した約109万件（使えるカード約34.5万、解約・期限切れなど約74.5万件）で、カード番号全桁・生年月日・MUJI Card ID、一部は氏名・住所・電話番号・性別・メールアドレスも含む。カード名義・有効期限・セキュリティコードは含まれない（[クレディセゾン](https://www.saisoncard.co.jp/customer-support/information/20261104/)）。アプリ・ネットストアにカードを登録した人の一部（約120件、番号の先頭6桁と下2桁・名義）も対象と報じられている（[オリコンニュース](https://www.oricon.co.jp/news/2490752/full/)）。
- 【2026-11-04夕追記】不正アクセスの発生は10月29日午前1時頃（[クレディセゾン](https://www.saisoncard.co.jp/customer-support/information/20261104/)）。
- 【2026-11-09夕追記】良品計画は11月6日16時、さらなるセキュリティ強化のため無印良品ネットストアを一時停止し、MUJIアプリも会員証バーコード表示以外の機能を止めた（第三報）。当初は1〜2日以内の再開を目途としていた（[良品計画 第三報](https://www.ryohin-keikaku.jp/news/articles/2026_1106_01)）。
- 【2026-11-09夕追記】11月9日の第四報で、ネットストアに対し、外部で不正に入手された可能性のあるパスワード等を使った多数のログイン試行（リスト型攻撃）があり、本人以外による不正ログインが行われた可能性があるとわかった。同社は「監視体制を強めていた中での更なる不正アクセス」とし、ネットストアの再開を延期した。再開時期は未定で、再開時は全員にパスワード再設定を求める方向（[良品計画 第四報](https://www.ryohin-keikaku.jp/news/articles/2026_1109_01)）。
- 【2026-11-09夕追記】あわせて、2020年1月2日〜2025年2月10日に店舗・ネットストアで代金引換配送の受取先になった人の情報の一部にも不正アクセスがあったと公表した。報道によると、件数は配送先の氏名・郵便番号約44万件（依頼主の情報は含まない）。リスト型攻撃で購入履歴・ポイント情報まで見られた可能性があるのは約27万件、氏名・住所・電話番号も対象の件数は約52万件から約75万件に修正された。対象者には11月10日から良品計画とクレディセゾンがメールか郵送で連絡する（[良品計画 第四報](https://www.ryohin-keikaku.jp/news/articles/2026_1109_01)、[WWDJAPAN](https://www.wwdjapan.com/articles/2547493)）。

- 【2026-11-12夕追記】良品計画は11月12日に清水智社長が記者会見を開き、不正アクセスを許したのは「当社のシステムの一部に脆弱性があったため」と説明した。脆弱性は修正済みとしたが、具体的な内容は「同様の攻撃を招く恐れがある」として回答しなかった。加えて、不正に入手されたとみられるIDとパスワードによる大量のログインも検知したとした（[テレ朝NEWS](https://news.tv-asahi.co.jp/news_economy/articles/900204081.html)、[TBS CROSS DIG](https://newsdig.tbs.co.jp/articles/withbloomberg/3080540?display=1)）。
- 【2026-11-12夕追記】会見での経緯説明によると、MUJIアプリへの不正アクセスは10月29日早朝に検知し、同日に社長を委員長とする危機管理本部を設置した。ネットストアへの不正アクセスは11月1日深夜に検知し、11月4日までに遮断した。ネットストアへの不正ログインの試みは10月29日ごろから目立っており、11月7日にリスト型攻撃の可能性が高いと判断した（[テレ朝NEWS](https://news.tv-asahi.co.jp/news_economy/articles/900204081.html)、[ITmedia ビジネスオンライン](https://www.itmedia.co.jp/business/articles/2611/12/news056.html)）。
- 【2026-11-12夕追記】MUJI Cardの番号は2021年7月までに取得をやめ、それまでの番号は削除する運用に変えていたが、実際には破棄していなかった。全桁のカード番号や退会者の情報がシステムに残っていたことを認め、「必要のない情報を持たない仕組みづくり」を進めるとした。カードの再発行手数料は良品計画が負担し、不正利用があれば補償する方針（[テレ朝NEWS](https://news.tv-asahi.co.jp/news_economy/articles/900204081.html)）。
- 【2026-11-12夕追記】会見で示した件数（11月11日時点）は、会員情報が最大2,726万件（うち氏名・住所・電話番号も対象が75万件）、不正ログインが確認されたアカウント約27万件、MUJI Card約109万件（うち有効34.5万件）、登録クレジットカードの一部約120件、代引き配送先約44万件で、第四報からの変更はない。ネットストアの再開時期は11月12日時点でも未定（[テレ朝NEWS](https://news.tv-asahi.co.jp/news_economy/articles/900204081.html)、[日経クロステック](https://xtech.nikkei.com/atcl/nxt/news/24/03464/)）。

### 関係しそうな既知の手口

## 概要

- 無印良品のアプリから、メールアドレスと生年月日・性別が最大約2,726万件流出した可能性がある。
- 氏名や住所、カード情報は含まれない。退会した人の情報も対象に入っている。（【2026-11-04追記】第二報で訂正。ネットストア会員も対象で、一部は氏名・住所・電話番号、MUJI Cardのカード番号なども対象）
- 「修正の適用」をしたとしており、アプリ側の何らかの弱点が突かれたとみられるが、内容は明らかにされていない（考察）。

## 発表内容の整理

**事実（良品計画、10月30日）**

| 項目 | 内容 |
| --- | --- |
| 対象サービス | 無印良品の公式アプリ「MUJIアプリ」 |
| 件数 | 最大約2,726万件（退会者を含む） |
| 項目 | メールアドレス、生年月日、性別 |
| 含まれない情報 | クレジットカード情報、氏名、住所、電話番号など |
| 対応 | アクセスの遮断、修正の適用、開発会社・関係会社と監視体制を強化 |
| 二次被害 | ダークウェブ等への流出、悪用の被害は確認されていない |
| 連絡 | 対象者へ順次連絡。外部流出が確認されれば改めて公表 |

報道によると、公表は会員向けセール「無印良品週間」の期間中だった（[ITmedia NEWS](https://www.itmedia.co.jp/news/article/2610/30/2000002756/)）。

**考察**

流出の可能性がある項目が3つに限られている点からは、攻撃者が触れられたのは会員データベース全体ではなく、メールアドレスと属性を返す一部の機能やテーブルだった可能性がある。ただし発表は侵入経路に触れておらず、断定できない（考察）。

件数に退会者が含まれることは、退会後もアプリ側に情報が残っていたことを示している。保持の理由や期間は説明されていない。

**事実（良品計画・クレディセゾン、11月4日）**

| 項目 | 内容 |
| --- | --- |
| 対象の拡大 | 最大約2,726万件に無印良品ネットストア会員も含む。一部は氏名・住所・電話番号も対象 |
| MUJI Card | 2000年10月〜2021年7月入会の約109万件。カード番号全桁、生年月日、MUJI Card ID（一部は氏名・住所・電話番号・性別・メールアドレスも）。名義・有効期限・セキュリティコードは含まない |
| 対応 | 対象者へメールか郵送で個別連絡。クレディセゾンが不正利用の監視を強化し、希望者にカードを再発行 |
| 二次被害 | ダークウェブ等への流出や悪用、MUJI Cardの不正利用の増加は確認されていない |

**考察（11月4日追記）**

第一報の「氏名・住所・電話番号・カード情報は含まれない」という説明は4日後に覆った。2021年7月にカード番号の連携をやめた後も、過去に受け取った番号全桁がシステムに残っていたことが被害を広げており、使わなくなったデータを消さずに置いていたことの影響が大きい（考察）。

## 関係しそうな既知の手口

**事実（既知の知見）**

- JPCERT/CCは2026年10月の注意喚起で、国内組織で相次ぐ不正アクセスの類型として、既知の脆弱性の探索、管理用APIへの不正なリクエスト、データ分析ツールMetabaseの脆弱性、Webシェルの設置を挙げた（[JPCERT/CC](https://www.jpcert.or.jp/at/2026/at260030.html)）。
- 10月30日には松屋フーズも公式アプリの管理システムへの不正アクセスを公表している（[松屋フーズの記事](/security-notes/notes/2026-10-31-matsuya-official-app-admin-system-intrusion/)）。

**考察**

小売の会員アプリは会員数が大きく、APIの認可に一か所でも抜けがあると、短時間で大量の件数を取られやすい。今回の原因は公表されていない（考察）。

## 利用者・運用者がいまできること

- 【2026-11-04追記】2021年7月以前にMUJI Cardに入会した人は、利用明細を確認し、身に覚えのない利用があればクレディセゾンに連絡する。再発行も受け付けている。
- 【2026-11-09追記】ネットストアと同じメールアドレス・パスワードを他のサービスでも使っている人は、他のサービス側のパスワードを変える。ネットストア再開後は他社と異なるパスワードを設定する（良品計画の呼びかけ）。
- MUJIアプリの利用者（退会した人を含む）は、無印良品を名乗るメールのリンクからログインや個人情報の入力をしない。生年月日を知っている前提の文面にも注意する。
- アプリ運営者は、退会者データの保管期間と削除の手順を見直し、APIの応答に不要な項目が含まれていないか確認する。
