# 大阪府 ― 食費支援事業の申請システムから本人確認書類の画像が漏えい

## 要点

### 発表された事実

- 大阪府は2026年11月13日、「大阪府子ども・大学生等への食費支援事業」で委託事業者が保守管理を行っていた申請システムに第三者による不正アクセスがあり、申請者と対象者計12名の個人情報が漏えいしたと発表した（[大阪府 11月13日報道提供](https://www.pref.osaka.lg.jp/hodo/fumin/o090010/prs_51051.html)）。
- 漏えいしたのは申請時に本人確認書類として提出された画像ファイル12名分（保護者と18歳以下の子どもの6組）。マイナンバーカード（表面）、運転免許証（表面）、健康保険証（両面）で、氏名、住所、生年月日、顔写真、免許証番号、優良・一般運転者の別、保険者名が含まれる（同）。
- うち1名分は、メールアドレス欄と電話番号欄に無関係の番号などが追記されていた（同）。
- 委託事業者は10月19日、10月17日（土）に不正アクセスされた痕跡を見つけ、直ちに外部からのシステムアクセスを閉鎖して府に報告した。ログ点検で、不正アクセスは10月17日14時53分から22時30分までと確認した（同）。
- 原因は、システムの脆弱性を悪用した不正アクセスで、本人確認書類の画像データが閲覧・取得可能な状態になったこと（同）。
- 府は10月22日に該当する申請者へ電話で説明・謝罪した（同）。
- 府と共同で事業を行った堺市によると、これとは別に、委託事業者が使う外部メール配信サービスへの不正アクセスで申請者のメールアドレスが漏えいしたおそれがあり、有無と件数は府が調査中。12名分に堺市民は含まれていない（[堺市 11月13日更新](https://www.city.sakai.lg.jp/kosodate/hughug/kosodatekankyo/kosodate/syokuhishienjigyou.html)）。産経新聞はこのメール配信サービスをアララと報じている（[産経ニュース](https://www.sankei.com/article/20261113-QE4XJ326T5KXBKBQI5YOS7MHUY/?outputType=asynd)）。

### わかっていないこと

- 悪用された申請システムの脆弱性の内容と、システムの製品名・委託事業者名。
- 約8時間の不正アクセスの間に、12名分以外の画像やデータが閲覧されていないと判断した根拠。
- メール配信サービス経由のメールアドレス漏えいの有無と件数。
- 10月の発見・本人への連絡から、11月13日の公表まで約1か月かかった理由。

### 関係しそうな既知の手口

- （考察）自治体の給付・商品券事業で、委託先が用意した申請・決済システムが狙われる事案が続いている。本人確認書類の画像は、なりすましでの口座開設や契約に悪用されやすい情報で、マネックス証券の件でも本人確認画像が対象になっている（[マネックス証券 ― 委託先の口座開設システムに不正アクセス、情報漏えいのおそれ](https://color4pen.github.io/security-notes/notes/2026-11-13-monex-account-opening-system-contractor-unauthorized-access/)）。

## 発表内容の整理

**事実（大阪府の11月13日の報道提供による）**

| 項目 | 内容 |
| --- | --- |
| 対象 | 食費支援事業の申請システム（委託事業者が保守管理） |
| 期間 | 2026年10月17日 14:53〜22:30 |
| 漏えい | 本人確認書類の画像12名分（6組） |
| 書類 | マイナンバーカード表面、運転免許証表面、健康保険証両面 |
| 原因 | システムの脆弱性を悪用した不正アクセス |
| 対応 | 外部からのアクセスを閉鎖、不審なアクセスの監視体制を強化 |

**考察**

- 事業の利用期間が9月に終わった後も、本人確認書類の画像を残した申請システムが外部から到達できる状態だった。給付事業のように期間が決まっているシステムは、終了後に画像を消すかアクセスを閉じるだけで、被害の範囲を大きく減らせる。
- 1名分の連絡先欄に無関係の番号が追記されていたことは、攻撃者が閲覧だけでなくデータを書き換えられたことを示している。
- 発見から約1か月、本人への連絡はしたものの公表は11月13日だった。同時期にメール配信サービスの件が判明したことで、まとめての公表になった可能性がある（発表は理由を示していない）。

## 利用者・運用者がいまできること

- 申請者：大阪府や事業をかたるメール・電話で、IDやパスワード、カード情報を求められても応じない。不審な場合は府の窓口に確認する。
- 本人確認書類の画像が漏れた場合に備え、信用情報機関への本人申告制度があることを知っておく（対象者は府から連絡を受けている）。
- 自治体：委託先のシステムに本人確認書類の画像がいつまで保存されるかを契約で決め、事業終了後の削除と外部公開の停止を確認する。
