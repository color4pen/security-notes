# ラクスル ― 認証情報を悪用され印刷データなどが流出したおそれ

## 要点

### 発表された事実

- ラクスルは2026年11月9日、「ラクスル」のデータ入稿の処理に関わるシステムが第三者の不正アクセスを受け、保管していた印刷データなどに含まれる個人情報が外部に流出したおそれがあると発表した（[ラクスル](https://corp.raksul.com/news/press/261109_unauthorized-access/)）。
- 発覚は11月8日0時20分ごろ。同社システムの認証情報が不正に取得され、保管データの一部に外部からアクセスできる状態にあったことを確認した（同）。
- 対象は入稿された印刷データと、請求書・Web郵便などのデータに記載された氏名・会社名・住所・電話番号・メールアドレスなど。件数は集計中、対象期間は「調査中〜11月8日」（同）。
- 印刷データには注文者だけでなく、名刺やはがきなど印刷物に記載された人の情報が含まれる場合がある（同）。
- クレジットカード情報、ログインID、パスワードは漏えいしていないことを確認した（同）。
- 不正に使われた認証情報の無効化、使われたアカウントの停止を行った。11月8日から入稿を伴う一部サービスを止め、9日7時から順次再開したが、ラクスル パッケージ、Adobe Express連携、デザイン制作依頼、カタログサイトは停止を続けている（同）。

### わかっていないこと

- 認証情報がどこから、どのように取得されたか。
- 件数と、対象期間の始まり（いつからアクセスできる状態だったか）。
- 実際に外部へ持ち出されたデータの量。
- 印刷物に名前が載っている第三者への通知方法。

### 関係しそうな既知の手口

- （考察）クラウド上の保管領域にアクセスする鍵が漏れてデータを持ち出される例は国内でも続いている（例：[iDA「MyBRANDS」](https://color4pen.github.io/security-notes/notes/2026-11-02-ida-mybrands-cloud-access-key-misuse/)）。ラクスルの「認証情報」が何を指すかは公表されていない。

## 概要

- 発覚から約1日半で第一報を出し、サービスの部分停止と再開状況もあわせて示している（[ラクスル](https://corp.raksul.com/news/press/261109_unauthorized-access/)）。
- 停止の影響で、データチェックや出荷に通常より時間がかかる場合があるとしている（同）。

## 発表内容の整理

**事実（ラクスルの発表による）**

| 項目 | 内容 |
| --- | --- |
| 対象システム | 「ラクスル」のデータ入稿の処理に関わるシステム |
| 原因 | システムの認証情報の不正取得 |
| 対象データ | 入稿された印刷データ、請求書、Web郵便などのデータ |
| 含まれうる情報 | 氏名、会社名、住所、電話番号、メールアドレスなど |

| 対象期間 | 調査中〜2026年11月8日 |

| 二次被害 | 発表時点で未確認 |

出典：[ラクスル「当社システムへの不正アクセスによる個人情報漏えいのおそれについて」（2026-11-09）](https://corp.raksul.com/news/press/261109_unauthorized-access/)

**考察**

- 名刺やDM、はがきの印刷データは、注文者の顧客や取引先など、ラクスルと契約していない人の情報をまとめて含む。漏えいした場合、本人が自分の情報が対象かどうかを知る手段がない点が、会員データの漏えいと違う。
- 請求書のデータは、取引先名と金額の組み合わせを含みうるため、請求書を装った詐欺に使われやすい種類の情報である。

## 関係しそうな既知の手口

**事実**

- 同社は「認証情報が不正に取得された」と述べているが、取得経路は調査中としている（[ラクスル](https://corp.raksul.com/news/press/261109_unauthorized-access/)）。

**考察**

- 長期間有効な認証情報（アクセスキーやサービスアカウントの鍵）が、開発端末やリポジトリ、委託先経由で漏れるのはよくある経路である。有効期限の短い認証情報への切り替えや、保管データへのアクセスの監視が効く。

## 利用者・運用者がいまできること

- 利用者：ラクスルや取引先を名乗る請求・支払い変更の連絡は、別の連絡手段で確認する。名刺やDMを印刷した場合は、記載された相手にも不審な連絡があり得ることを念頭に置く。
- 運用者：入稿データなど大量の個人情報を含むファイルの保管期間を見直し、不要になったものは消す。保管領域への鍵は用途ごとに分け、異常な一括ダウンロードを検知する。
