# グッドスマイルカンパニー公式ショップ ― 脆弱性を突いた不正アクセスで約3日半にわたり管理情報が閲覧され、会員の氏名・住所・注文履歴・カード下4桁と有効期限に流出の可能性、サイトは閉鎖

## 要点

### 発表された事実

- グッドスマイルカンパニーは2026年10月23日、運営するECサイト「グッドスマイルカンパニー公式ショップ」で第三者による不正アクセスが発生し、会員の個人情報等が不正に閲覧されたことが確認されたと発表した（[グッドスマイルカンパニー カスタマーサポート](https://support.goodsmile.com/hc/ja/articles/63547468806297)）。
- システムログの解析で、2026年10月19日15時過ぎ頃から10月22日22時頃にかけて、サイトの管理情報に複数回の不正アクセスによる閲覧があったことが判明した。詳細は確認中（同）。
- 閲覧された可能性があるのは、基本情報（氏名、読み仮名、性別、住所、電話番号、メールアドレス）、注文情報（注文日、商品名、数量、金額、別途登録したお届け先の住所・氏名・電話番号、決済方法、決済状況）、クレジットカード情報（ブランド、番号下4桁、有効期限）。カード名義、カード番号の全桁、セキュリティコードは含まれない（同）。
- 原因は調査中だが、現時点では「脆弱性による不正アクセス」と認識している。原因と思われる脆弱性を改修し、システムのセキュリティを強化した。判明後ただちにサイトを閉鎖し、再開の見込みは示していない。10月23日に個人情報保護委員会へ報告した（同）。
- 対象となる可能性のある会員には、確認が済み次第、順次個別のメールで知らせる予定。問い合わせフォームはショップとは別のシステムで運用している（同）。

### わかっていないこと

- 対象となる会員・注文の件数
- 悪用された脆弱性の種類（自社開発か、ECパッケージ・プラグインか）と、10月21日公表のPHPの脆弱性との関係
- 「管理情報」とは何か（管理画面・管理者用API・データベースのどれか）と、閲覧にとどまらず取得（持ち出し）されたかどうか
- 10月22日22時頃に不正アクセスが止まった理由（検知・遮断か、攻撃側の終了か）
- 海外向けショップなど、ほかの販売サイトへの影響
- サイトの再開時期

### 関係しそうな既知の手口

- （考察）ECサイトの管理機能を脆弱性経由で開かれ、会員情報と注文情報を閲覧される形は、10月に国内で相次ぐEC・会員サイトの事例と同じ型に見える。カードの下4桁と有効期限は単体では決済に使えないが、氏名・住所・注文履歴と組み合わせると「ご注文のカードの確認」を装うフィッシングの材料になる。

## 概要

- フィギュアなどのホビー商品を扱うグッドスマイルカンパニーの公式ECサイトで、約3日半にわたって管理情報が不正に閲覧された。
- 会員の連絡先と注文履歴に加え、カードのブランド・下4桁・有効期限が閲覧された可能性がある。
- 原因は脆弱性とみられ、サイトは閉鎖中。件数はまだ出ていない。

## 発表内容の整理

**事実（グッドスマイルカンパニーの発表）**

| 項目 | 内容 |
| --- | --- |
| 対象サイト | ECサイト「グッドスマイルカンパニー公式ショップ」 |
| 期間 | 2026年10月19日15時過ぎ頃〜10月22日22時頃（複数回） |
| 基本情報 | 氏名、読み仮名、性別、住所、電話番号、メールアドレス |
| 注文情報 | 注文日、商品名、数量、金額、お届け先の住所・氏名・電話番号（別途登録した場合）、決済方法、決済状況 |
| カード情報 | ブランド、番号下4桁、有効期限（名義・全桁・セキュリティコードは含まない） |
| 原因 | 脆弱性による不正アクセス（調査中） |
| 対応 | サイト閉鎖、脆弱性の改修、セキュリティ強化、個人情報保護委員会への報告、対象会員への個別メール（予定） |

- ゲーム・ホビー系メディアも同じ内容を伝えている（[Game*Spark](https://www.gamespark.jp/article/2026/10/23/174018.html)、[電撃オンライン](https://dengekionline.com/article/202610/91935)）。

**考察**

カード番号の全桁やセキュリティコードがないのは、ショップがカード情報を自社で保持しない（決済代行に任せる）作りになっているためと考えられ、決済への直接の被害は避けられた形だ。一方で、下4桁と有効期限、注文した商品名がそろうと、本物の店舗からの連絡にしか見えないメールやSMSを作れる。限定品の予約・抽選など、ファンが反応しやすい文面が使われるおそれがある（考察）。

発表は「閲覧されたことが確認された」と書く一方、表題と項目では「可能性」としている。どの会員の情報がどの範囲で見られたかを、ログから絞り込んでいる途中と読める。件数と個別通知の対象がそろう続報が重要になる（考察）。

## 関係しそうな既知の手口

**事実（既知の知見）**

- JPCERT/CCは2026年10月8日（10月23日にも更新）、国内組織で相次ぐ不正アクセスについて注意喚起を出し、公開アプリの解析によるAPIの特定、内部APIの不正な呼び出しなどの手口を挙げて対策を求めている（[JPCERT/CC](https://www.jpcert.or.jp/at/2026/at260030.html)）。
- 10月21日にはPHPの重大な脆弱性2件（CVE-2026-109618／109619）が公表され、国内の複数の事業者が予防的にサービスを止めた（[PHP2Shellの記事](/security-notes/notes/2026-10-22-php2shell-cve-2026-109618-109619-oom-stale-state-rce/)）。

**考察**

不正アクセスの始まり（10月19日）はPHPの脆弱性の公表（10月21日）より前で、時期だけからは関係は読み取れない。グッドスマイルカンパニーは脆弱性の種類を明かしていない（考察）。

## 利用者・運用者がいまできること

- 公式ショップの会員は、グッドスマイルカンパニーやカード会社、配送業者を名乗るメール・SMS・電話のリンクを開かない。カード番号やセキュリティコードを入力させる連絡には応じない。
- カードの利用明細に覚えのない請求がないかを確かめる。
- 問い合わせは、ショップとは別システムのカスタマーサポートのフォームから行う。
- ECサイトの運営者は、管理画面や管理者用APIが外部から届く状態になっていないか、管理機能へのアクセスの異常を検知できるかを点検する。
