# UPSIDER「Breakthrough GRID」 ― 会員サイトから情報を持ち出された

## 要点

### 発表された事実

- 株式会社UPSIDERは2026年10月27日、会員制サービス「Breakthrough GRID」の会員向けサービスサイトが同日に第三者の不正アクセスを受け、保存されていた情報が持ち出されたと公表した（[UPSIDER](https://corp-news.up-sider.com/261027-pr-2/)）。
- 対象は会員本人の情報（氏名・メールアドレスなど）、所属企業の情報（企業名・部署など）、イベントに関する情報、ディスカッションの議事録など。退会済みの人も含む（同）。
- 日本経済新聞は、一部退会者を含む187社・計544人の情報が漏えいしたと報じた（[日本経済新聞](https://www.nikkei.com/article/DGXZQOUB2795D0X21C26A0000000/)）。
- 法人カード「UPSIDER」「PRESIDENT CARD」など他サービスの会員情報・カード情報・利用明細・決済情報を管理するシステムへの不正アクセスや流出はないことを確認した（[UPSIDER](https://corp-news.up-sider.com/261027-pr-2/)）。
- 会員サイトの全機能を停止し、外部からのアクセスを遮断した。再開時期は未定で、原因は調査中（同）。

### わかっていないこと

- 不正アクセスの原因と侵入経路
- 持ち出された情報の正確な件数（公式発表には件数の記載がない）
- 2026年4月の別の不正アクセス事案との関係の有無
- 会員サイトの再開時期と、他サービスの点検結果

### 関係しそうな既知の手口

- （考察）発生当日に公表し、持ち出された情報を「持ち出されたものとみなし」て対応している。攻撃者側からの接触や公開、または持ち出しを示すログなど、持ち出しを確信できる材料があった可能性があるが、公表されていない。

## 概要

- 企業の経営幹部・事業責任者が集まる会員制コミュニティの会員サイトが不正アクセスを受け、会員情報とディスカッションの議事録などが持ち出された。
- 報道では187社544人分。経営層の名前・所属と、議論の中身がまとめて外に出たことになる。
- 法人カードなど主力事業への影響はないとし、会員サイトは止めたまま原因を調べている。

> この記事では、公式発表・報道で確認できた内容を「事実」、筆者の推測や意見を「考察」として分けて書いています。確認できなかった情報は書いていません。

## 発表内容の整理

**事実（UPSIDER）**

| 項目 | 内容 |
| --- | --- |
| 対象サービス | 「Breakthrough GRID」の会員向けサービスサイト |
| 発生日 | 2026年10月27日 |
| 持ち出された情報 | 会員本人の情報（氏名・メールアドレスなど）、所属企業の情報（企業名・部署など）、イベントに関する情報、ディスカッションの議事録など（会員と退会済みの人） |
| 影響がないとした範囲 | 法人カード「UPSIDER」「PRESIDENT CARD」をはじめ、Breakthrough GRID以外のサービスの会員情報・カード情報・利用明細・決済情報を管理するシステム |
| 対応 | 会員向けサービスサイトの全機能を停止し外部からのアクセスを遮断。原因究明と再発防止策の策定、他サービスの点検 |
| 二次被害 | 現時点で確認されていない |

- 対象者には個別にメールで詳細を送っている。同社や関係者を装った不審なメール・電話・SNSメッセージに注意するよう呼びかけ、同社からパスワードやカード番号を尋ねることはないとしている。問い合わせはBreakthrough GRID事務局（grid@up-sider.com）（[UPSIDER](https://corp-news.up-sider.com/261027-pr-2/)）。

**事実（日本経済新聞）**

- UPSIDERはみずほ銀行傘下で法人クレジットカード事業などを手がける。一部退会済みを含む187社・計544人の情報が対象と報じた（[日本経済新聞](https://www.nikkei.com/article/DGXZQOUB2795D0X21C26A0000000/)）。

**考察**

件数は多くないが、漏れた情報の性質は重い。経営幹部の氏名・メールアドレス・所属・部署がそろった名簿は、経営層を装う詐欺メール（ビジネスメール詐欺）や標的型メールの宛先として価値が高い。さらにディスカッションの議事録には、参加企業の課題や計画など、外に出す前提でない話が含まれている可能性がある（考察）。

UPSIDERは4月にもサプライチェーン攻撃による不正アクセスを受けているが、今回の発表は4月の事案に触れておらず、関係があるかはわからない。別のサービスで別の原因である可能性も十分ある（考察）。

## 関係しそうな既知の手口

**事実（既知の知見）**

- JPCERT/CCは10月8日に公開し、その後更新している注意喚起で、国内で相次ぐ不正アクセスの類型として、既知の脆弱性の悪用や、窃取されたAPIキーなどを使った管理用APIへの不正なリクエストを挙げている（[JPCERT/CC](https://www.jpcert.or.jp/at/2026/at260030.html)）。

**考察**

コミュニティ運営のための会員サイトは、主力サービスに比べて開発・運用の優先度が低くなりがちで、外部のサービスやパッケージで作られていることも多い。今回の侵入経路は公表されていないが、主力の決済システムと切り離されていたことが、影響を会員サイトにとどめた形だ（考察）。

## 利用者・運用者がいまできること

- Breakthrough GRIDの会員・元会員は、UPSIDERからの個別メールを確認する。UPSIDERや会員企業の幹部、イベント関係者を名乗る連絡で、送金・ファイルの開封・ログインを求められたら、別の経路で本人に確認する。
- 議事録で話した内容に機密性の高いものがあった企業は、社内で影響を確認し、関係者に共有しておく。
- 企業向けコミュニティやイベントの会員サイトを運営する事業者は、主力システムと同じ水準で、会員情報や議事録へのアクセス権限と外部から届く入口を点検する。
