# アンビションDXホールディングス ― ネットワーク機器から侵入され、業務文書を持ち出された後にランサムウェア、最終報で約14万ファイルの持ち出しと個人情報約58万件の「漏えいのおそれ」

## 要点

### 発表された事実

- 株式会社アンビションDXホールディングス（東証グロース、3300）は2026年10月20日、8月に確認したランサムウェア攻撃を含む不正アクセスについて、外部専門機関のフォレンジック調査を踏まえた最終報を公表した（[最終報](https://www.nikkei.com/markets/ir/irftp/data/tdnr/tdnetg3/20261020/g6udgi/140120261020553634.pdf)）。
- 8月6日未明、第三者が同社ネットワークに不正に侵入し、同社とグループ会社のサーバー・端末などの一部に保管された業務文書を外部へ持ち出したうえで、ランサムウェアによる攻撃を行ったと推定している。侵入経路は「当社のネットワーク機器を経由」と推定し、攻撃手法の詳細は同種被害の防止と捜査への影響を考えて公表しない（同）。
- 件数は二つに分けて示された。攻撃者による持ち出しが確認された情報はファイル約14万件。持ち出しの可能性を否定できない範囲に保管されていた個人情報は約58万件で、公開の有無にかかわらず「漏えいのおそれ」として扱う（同）。
- 持ち出しの精査で特定された主な情報として、子会社ホープ少額短期保険の保険金支払い情報833件（保険金受取人の金融機関名・支店名・口座番号・口座名義を含む）、保険契約情報363件、解約契約情報465件、子会社アンビション・エージェンシーの契約書・入居審査資料449件、同社の賃貸借契約情報2件（年収や転居理由、同居人・緊急連絡先を含む）を挙げた。クレジットカード情報とマイナンバーは確認されていない（同）。
- 8月7日の第2報の時点では「データが外部へ持ち出された形跡は確認されていない」としていた（[第2報](https://f.irbank.net/pr/20260807/140120260807515802.pdf)）。

### わかっていないこと

- どのネットワーク機器の、どの脆弱性や認証情報が使われたのか（非公表）
- 約58万件の個人情報の内訳と、対象者への個別連絡の進み具合
- 攻撃者の名前（報道ではデータ恐喝グループ「Settra」が犯行を主張したとされるが、会社は攻撃主体を特定していない）

### 関係しそうな既知の手口

- （考察）ネットワーク機器（VPN装置やファイアウォールなど）を入口にして侵入し、データを持ち出してから暗号化する「二重恐喝」の典型的な流れに沿っている。

## 概要

- 8月に起きたランサムウェア攻撃について、2か月半の調査を経た最終報が出た。
- 入口はネットワーク機器と推定され、業務文書を持ち出した後に暗号化された。
- 持ち出しが確認されたのは約14万ファイル、漏えいのおそれがある個人情報は約58万件。保険金受取人の口座番号や、入居審査の勤務先・年収なども含まれる。

> この記事では、公式発表・報道で確認できた内容を「事実」、筆者の推測や意見を「考察」として分けて書いています。確認できなかった情報は書いていません。

## 発表内容の整理

**事実（最終報）**

| 項目 | 内容 |
| --- | --- |
| 侵入経路（推定） | 同社のネットワーク機器を経由した侵入。手法の詳細は非公表 |
| 攻撃の流れ（推定） | 業務文書を外部に持ち出したうえでランサムウェア攻撃 |
| 被害範囲 | 同社とグループ会社の一部のサーバー・端末に侵害の痕跡。侵害された機器は隔離を継続 |
| A. 持ち出しが確認された情報 | ファイル約14万件 |
| B. 漏えいのおそれ | 個人情報約58万件（Aのうち、持ち出しを否定できない範囲に保管されていたもの） |
| 含まれない | クレジットカード情報、マイナンバー（これまでの精査で確認されていない） |
| 二次被害 | 10月20日時点で確認されていない |
| 再発防止策 | 機器の更新と接続方式の見直し、管理画面の接続元制限、多要素認証の必須化、EDRの導入範囲拡大、全役職員・管理者のパスワード一斉変更と認証基盤の資格情報のリセット、侵害機器の再構築・廃棄、ネットワーク分離、フォルダの権限の最小化など |
| 業績への影響 | 2027年6月期への影響は軽微の見込み |

**考察**

第2報の「持ち出しの形跡は確認されていない」から、最終報の「約14万ファイルの持ち出しを確認」まで、評価が大きく変わった。発生直後の数日で「持ち出しはない」と言える材料は少なく、初期の発表は「現時点では確認できていない」以上の意味を持たない、という教訓になる（考察）。

再発防止策の最初に「機器の更新・接続方式の見直し、管理画面への接続元制限、アカウントの多要素認証の必須化」が並んでいる点から、入口になったネットワーク機器には、古い機種やファームウェア、管理画面がインターネットから届く状態、多要素認証のないアカウントのいずれかがあったと推測できる（考察。会社は手口を公表していない）。「認証基盤の資格情報のリセット」も挙げられており、侵入後にドメインの管理者権限まで取られた可能性もある（考察）。

保険金受取人の口座番号や、入居審査資料の勤務先・年収、同居人や緊急連絡先など、本人以外の情報まで含まれている。賃貸や保険の業務文書には、申込者以外の人の情報がまとまって入っていることが多く、持ち出されると影響が本人の外に広がる（考察）。

## 関係しそうな既知の手口

**事実（既知の知見・同種事例）**

- 大阪公立大学では仮想化基盤が狙われ、約500台のサーバーが停止し、バックアップの多くも暗号化された（[大阪公立大学の記事](/security-notes/notes/2026-10-06-osaka-metropolitan-university-ransomware-500-servers/)）。
- 池上通信機では、外部からの通報で発覚したファイル暗号化と、リークサイトへの情報公開があった（[池上通信機の記事](/security-notes/notes/2026-10-05-ikegami-tsushinki-ransomware-leak-site/)）。
- ジャパンタイムズでは、使い終えた管理部門のファイルサーバーがランサムウェア被害に遭い、攻撃者がデータを公開した（[ジャパンタイムズの記事](/security-notes/notes/2026-10-19-japan-times-ransomware-retired-file-server-leak/)）。

**考察**

- **ネットワーク機器は「境界の内側への鍵」**：VPN装置やファイアウォールは常にインターネットに出ているため、脆弱性の公開から悪用までが早い。更新の遅れや、使われなくなったアカウントの放置が、そのまま社内への入口になる（考察）。
- **持ち出しが先、暗号化が後**：暗号化に気付いた時点では、データはすでに外にある。バックアップからの復旧だけでは、漏えいの問題は解決しない（考察）。

## 利用者・運用者がいまできること

**事実（発表に基づく）**

- 同社は、同社やグループ会社、金融機関などを装ったなりすましメールや不審な電話・郵便物、口座の不正利用が起こる可能性は否定できないとしている（最終報）。

**考察（利用者向け）**

- ホープ少額短期保険で保険金を受け取ったことがある人は、受取口座の入出金に不審な動きがないか確認する。保険金や還付をうたう連絡には、まず公式の窓口に確かめる。
- 賃貸の申込や入居審査をした人、緊急連絡先や同居人として名前を書かれた人も、不審な連絡に注意する。

**考察（運用者向け）**

- インターネットに出ているネットワーク機器（VPN、ファイアウォール、ルーター）の機種・ファームウェア・管理画面の公開範囲・アカウントを一覧にし、サポート切れの機種は置き換える。
- 管理画面の接続元を絞り、VPNと管理者アカウントに多要素認証を必須にする。
- 大量の外向き通信を検知できるようにし、「暗号化の前の持ち出し」の段階で気付ける可能性を上げる。
