# ウィルズ「ネットマイル」 ― 不正アクセスで会員情報漏えいの可能性、サイト停止

## 要点

### 発表された事実

- ウィルズは、広告事業で運営する「ネットマイル」のシステム環境に第三者の不正アクセスがあり、会員の個人情報の一部が外部に漏えいした可能性があると公表した（[ウィルズ 適時開示](https://www.wills-net.co.jp/pdf/ir-news/uploads/e88675137464940b8b98c8c999d7c452f63571e7.pdf)）。
- 対象は最大約549万人（退会した会員を含む最大数）で、氏名、メールアドレス、その他の特典交換に関する情報。保存されている項目は会員ごとに異なる（同）。
- 二次被害の防止とセキュリティ対策のため、「ネットマイル」と「すぐたま」のサイトを停止している（同）。

### わかっていないこと

- 不正アクセスがいつ起き、いつ気づいたか。
- 侵入の経路と手口。
- 実際に漏えいした人数と項目、パスワードが含まれるか。

### 関係しそうな既知の手口

- （考察）ポイントサービスは、交換先や登録メールアドレスを狙ったアカウント乗っ取りやフィッシングの標的になりやすい。ウィルズ自身も、同社や金融機関・ポイント交換先を装う連絡への注意を呼びかけている。

## 概要

- 主語：ウィルズ（東証グロース上場、株主管理プラットフォーム事業が主力）
- 何が起きたか：旧子会社を起源とするポイントサービス「ネットマイル」のシステム環境に不正アクセスがあった
- 影響の可能性：最大約549万人（退会者を含む）の氏名・メールアドレス・特典交換に関する情報
- 保有していない情報：クレジットカード情報、マイナンバーカード情報など
- サービス：「ネットマイル」「すぐたま」のサイトを停止中

## 発表内容の整理

**事実（ウィルズによる）**

| 項目 | 内容 |
| --- | --- |
| 対象サービス | ネットマイル（旧子会社を起源とする事業） |
| 対象人数 | 最大約549万人（退会した会員を含む最大数） |
| 対象となる可能性がある情報 | 氏名、メールアドレス、その他の特典交換に関する情報（会員ごとに異なる） |
| 保有していない情報 | クレジットカード情報、マイナンバーカード情報など |
| 公開・悪用 | 現時点で確認されていない |
| 他事業への影響 | 「プレミアム優待倶楽部」「IR-navi」「IR-port」は別のシステム基盤・管理権限で運営しており、影響は確認されていない |
| 対応 | 「ネットマイル」「すぐたま」サイトを停止。対象者への通知と個人情報保護委員会への報告は法令に従って対応するとしている |
| 業績影響 | 2026年12月期への影響は軽微の見込み |

**考察**

- 対象に退会者が含まれるため、退会後も会員データが残っていたことになる。退会者のデータをどれだけの期間・範囲で残していたかが、被害範囲を大きくした可能性がある。
- 「特典交換に関する情報」の中身は示されていない。交換先の口座やポイントアカウントの識別子が含まれるかどうかで、二次被害のリスクは変わる。

## 関係しそうな既知の手口

**事実**

- ウィルズは手口を公表していない。会員には、同社や金融機関・ポイント交換先を装った不審なメール・SMS・電話に注意し、URLを開いたりパスワードや暗証番号を入力したりしないよう呼びかけている（[ウィルズ 適時開示](https://www.wills-net.co.jp/pdf/ir-news/uploads/e88675137464940b8b98c8c999d7c452f63571e7.pdf)）。

**考察**

- 氏名とメールアドレスの組み合わせは、ポイント失効や交換手続きを装うフィッシングにそのまま使える。

## 利用者・運用者がいまできること

- 会員・元会員：ネットマイルやポイント交換先を名乗るメール・SMSのリンクを開かない。ネットマイルと同じパスワードを他のサービスで使っている場合は、そちらを変更しておく。
- 運用者：退会者データの保存期間と削除の運用を見直す。統合・買収などで引き継いだ旧システムが、主力事業と同じ水準で管理されているかを点検する。
